# Triage labels

技能使用以下五个 canonical triage 角色；右侧是本仓库的实际标签字符串。

| Canonical 角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估 |
| `needs-info` | `needs-info` | 等待提问者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

## 额外标签

- `resolved`：问题已解决。
- `need-review`：需要进行评审。

额外标签不替换上述五个 canonical triage 状态。
