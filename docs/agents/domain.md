# Domain docs

工程技能在探索代码库前，读取以下领域文档：

- 根目录的 `CONTEXT.md`
- `docs/adr/` 中与当前工作区域相关的 ADR

如果这些文件不存在，继续工作即可，不要将缺失本身报告为问题，也不要预先创建它们。`/domain-modeling` 会在领域术语或决策实际确定时按需创建。

## 使用领域术语

在 Issue 标题、重构建议和测试名称中使用 `CONTEXT.md` 定义的领域术语。不要改用该词汇表明确避免的同义词。

如果需要的概念尚未出现在词汇表中，这通常表示需要先通过 `/domain-modeling` 补充领域模型。

## ADR 冲突

如果输出内容与现有 ADR 冲突，应明确指出冲突，不要静默覆盖。例如：

> 与 ADR-0007 冲突，但由于……值得重新审议。
