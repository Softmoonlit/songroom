# 全站深色模式主题系统与三态切换

点歌台采用深度声学深灰蓝（Slate/Zinc + Indigo）色板，提供“跟随系统 / 浅色 / 深色”三态视觉主题，以降低夜间与暗光环境下的视觉疲劳，并保持原有的现代音乐质感。

## 背景与权衡

1. **视觉偏好与环境光线适应**：宿舍协作点歌常发生在傍晚或夜间暗光环境下，浅色高亮白底容易产生刺眼与视觉疲劳。
2. **纯媒体查询 vs 手动切换**：纯媒体查询无法满足不同环境光线下临时手动切换的需求；纯手动切换无法在新设备打开时自动匹配用户系统偏好。因此确定采用三态策略：默认跟随操作系统偏好（`prefers-color-scheme: dark`），同时允许用户显式指定浅色或深色，偏好持久化保存在当前浏览器 `localStorage` 中。
3. **防闪烁（FOUT/Flash of Unstyled Theme）机制**：在 SPA 单体的 `index.html` 的 `<head>` 中置入无依赖的微型内联脚本，在 DOM 渲染前同步读取 `localStorage` 与系统匹配媒体查询，将计算得出的有效主题（`light` 或 `dark`）直接置于 `document.documentElement` 的 `data-theme` 属性上，杜绝白屏/黑屏闪烁。
4. **色彩基调决策**：不使用纯黑（`#000000`）高对比 AMOLED 风格，而是采用带深度冷蓝微弱色相的深灰（主背景 `#0b0f19`、卡片表面 `#151d30`、悬浮层 `#1e293b`、文字 `#f1f5f9`），并将主色（Indigo）适度提亮为 `#6366f1` / `#818cf8`，保持与浅色模式一致的层次感与按压触感。

## 规范与接口约束

- **主题标记**：根元素通过 `data-theme="dark"` 与 `data-theme="light"` 承载，全局 CSS 变量在 `:root`（浅色基础）与 `[data-theme="dark"]`（深色覆盖）中集中定义。
- **切换控件**：在全局顶部导航栏右侧（未登录时在主标题侧、已登录时在用户信息旁）提供单个循环切换图标按钮，依次在 `system`（💻）→ `light`（☀️）→ `dark`（🌙）之间循环流转，更新即刻反映至 `document.documentElement` 并写入 `localStorage`。
- **系统监听**：当偏好设为 `system` 时，通过 `window.matchMedia('(prefers-color-scheme: dark)')` 的 `change` 事件实时响应操作系统的主题切换。
