# 成员自主绑定个人歌单与多账号去中心化点歌

Status: accepted (supersedes ADR-0005)

废除由房主在自身网易云账号下为室友统一分配来源歌单的中心化模型，改为全员（包含房主与室友）在房间内自主绑定本人已授权网易云账号下的歌单作为只读点歌来源。

## 核心设计与权责边界

1. **多账号来源与去中心化绑定**：
   - 每个点歌台成员（包括房主与室友）均可在全局「账号设置」中独立授权绑定自己的网易云音乐账号。
   - 成员进入房间后，在「我的歌单」页面中自主选择绑定本人账号下的歌单，候选覆盖本人的「我喜欢的音乐」、自建歌单（含私密）及收藏歌单。
   - 房主不再持有替室友分配、更换或解绑歌单的权限。房间成员列表中彻底移除分配/更换/解绑及“查看歌单”操作，保护各室友的私密歌单与收藏隐私；角色标签左移与昵称紧凑聚合。

2. **公共歌单与写入授权归属**：
   - 房间的公共歌单依然由房主主动新建，归属房主网易云账号并由点歌台维护专用生命周期。
   - 无论成员逐首点歌还是房主发起随机点歌，向公共歌单的添加与替换写入操作严格使用**房主的网易云授权**执行。
   - 各成员自身的网易云授权仅用于拉取本人绑定的个人歌单快照及候选列表。

3. **严格一致性与双账号校验**：
   - **逐首点歌**：严格要求点歌成员自身网易云授权有效（active）且房主授权有效。若点歌成员自身授权失效，拒绝点歌并提示先重新授权，不凭旧快照放行。
   - **随机点歌**：房主发起随机换歌时，弹窗中未绑定歌单或授权失效的成员自动置灰禁用并标注原因；抽选时使用各自成员凭证拉取最新歌曲，任一选定成员歌单读取失败则整次抽选报错，不凭旧快照掩盖异常。最终由房主授权执行批量清空与添加替换。

4. **严格只读与极简交互**：
   - 个人歌单在点歌台内绝对只读，不提供网页加歌、删歌、排序或全网搜索功能；曲目增删完全在网易云官方客户端维护，点歌台提供手动刷新。
   - 「我的歌单」操作极简化：未绑定歌单时显示「绑定歌单」，已绑定时显示「更换歌单」，不设独立的解绑按钮；若未绑定网易云账号，提示文案引导前往全局账号设置页扫码授权。

5. **无害化生命周期**：
   - 成员更换个人歌单、退出房间或被移出房间时，仅清除本地关联和该成员在公共歌单上的点歌人标签；成员账号级的网易云授权完全保留，云端歌单毫发无损，不生成任何云端清理任务。
   - 房主删除房间时，仅随房间清理公共专用歌单，所有个人歌单仅解除本地引用。
