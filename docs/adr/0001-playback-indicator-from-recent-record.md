# 播放指示采用最近播放记录

点歌台使用房主授权网易云账号的最近一条歌曲播放记录，在本房间公共歌单中标记同一歌曲，并提供“定位到正在播放”入口。用户明确选择歌曲前的动态图标和定位按钮，取消“房主最近播放”可见说明，以保持界面简洁。

此决议接受最近播放记录作为播放线索：现有接口证据提供账号歌曲记录与时间，没有指定设备的实时播放、暂停或进度保证。领域上将该能力称为“播放指示”，不将它扩展为读取、修改或同步官方客户端播放队列的能力；不依据歌曲时长推算切歌、暂停或播放进度。

记录在进入公共歌单页和页面恢复可见时立即更新，页面可见期间每 30 秒更新；点击“同步歌单”同时更新记录。同一真实账号的请求合并，不因房间或查看人数重复轮询；歌单内容继续按需同步。无记录、最新记录歌曲不在当前歌单或读取失败时隐藏歌曲指示，保留并禁用定位按钮，读取失败仅提供简短反馈。

决议来源及接口证据见[房间体验修订票](../../.scratch/room-experience-refinement/issues/01-clarify-noise-scroll-order-and-playback.md)，完整交互与验收见[规格](../../.scratch/room-experience-refinement/spec.md)。正式接入与真实接口验收尚未完成。
