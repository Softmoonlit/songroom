# 个人歌单统一专用与先存歌后点歌

房主与室友统一按需在房主音乐平台账号下为当前房间创建可写个人歌单，不再绑定已有自建或收藏歌单，也不跨房间共用。房间默认展示独立搜索页，搜索只添加自己的个人歌单；逐首公共点歌只从自己的个人歌单发起，以统一可写来源和使用流程，避免房主使用只读收藏来源时无法搜索存歌。

这一选择放弃已有来源直接复用与直接搜索公共点歌。专用个人歌单随成员或房间生命周期清理，房主个人歌单也随删房删除；原有自建或收藏来源只解除点歌台关联，保留云端歌单和收藏，不自动迁入新歌单。

详细规则与验收见[功能规格](../../.scratch/song-search-page/spec.md)。本决议记录已逐项确认的产品规则，实施状态以功能规格及实现工单为准。
