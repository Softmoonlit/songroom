# 更换音乐平台账号终止原账号的业务与恢复责任

用户确认：更换真实音乐平台账号后，与原账号相关的状态和任务全部失效。保留房间、成员、昵称、邀请和仍有效申请，清除原账号授权、歌单绑定、快照、公共点歌人标签、搜索与随机换歌预览，并终止原账号全部未完成操作和清理任务，包含创建未知和删除未知；不再补授权、查询确认、恢复旧绑定或继续清理。保留既有必要的最小防重与管理员审计事实，不保留可恢复的旧业务载荷。

这一决议接受已经发出的请求可能在网易云生效、旧云端资源可能残留且不再由点歌台追查的后果。换号本身不迁歌、不自动创建歌单、不主动删除旧云端资源；晚到响应不能恢复旧业务数据或影响新账号配置。原账号不因已终止任务继续占有业务归属。暂时退出授权、凭据失效及原账号重新授权仍沿用原恢复规则，成员退出和删房在没有换号时仍保留必要清理责任。

本决议替代旧 MVP 工单 32、35 及其他规格中“换号后保留原账号最小任务、给旧任务补授权并持续占有原账号”的要求。现有随机换歌恢复规则中“可能已发只查明原目标”同样不再适用于明确换号后的旧任务；普通超时、重启或暂时授权失效仍只确认、不重发。取舍是以明确换号作为原账号责任的终止边界，放弃旧任务最终收敛保证，避免维护多个账号的恢复授权。

决议来自本轮剩余工单可执行性讨论中用户对换号语义的明确修订；本文记录已确认规则，账号切换及相关终止逻辑尚待工单实施，不表示当前代码已支持换号。
