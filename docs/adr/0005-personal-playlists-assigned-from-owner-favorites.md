# 个人歌单绑定房主收藏与房主分配

Status: accepted (supersedes ADR-0002)

废除成员在房主网易云账号下主动新建专用个人歌单及全网搜索存歌机制，全员个人歌单改为由房主从其网易云账号收藏的歌单中为成员分配作为只读点歌来源，且允许多名成员绑定同一收藏歌单。彻底移除全网搜索歌曲与直接点歌能力，点歌台歌曲全部由成员从已分配的收藏歌单逐首点入，或由房主通过「随机点歌」从已分配成员的歌单中抽选。

这一取舍放弃了成员在点歌台内自主创建专用歌单、全网搜索存歌与修改歌单歌曲的能力，换取免去在外部平台主动创建和清理专用云端资源的复杂性，回归纯粹基于房主收藏歌单进行点歌与随机播放。收藏歌单在成员退出或删房时仅解除本地关联与快照引用，绝不调用网易云接口删除外部歌单或取消收藏。
