# 个人歌单由房主统一分配已有来源

Status: superseded by ADR-0006 (superseded ADR-0002)

废除成员在房主网易云账号下主动新建专用个人歌单及全网搜索存歌机制，全员个人歌单改为由房主统一分配已有歌单作为只读点歌来源。候选包括房主已授权网易云账号收藏的有效歌单、该账号自建歌单（含私密歌单）及「我喜欢」；不再限定为他人创建的收藏歌单。房主为自己与室友统一分配、更换或解除分配，允许多名成员绑定同一来源。

所有候选在点歌台内均只读。来源在网易云是否可写不改变这一约束，房主自建歌单、私密歌单和「我喜欢」也不提供添加、删除、排序歌曲或修改收藏状态的操作。私密来源通过房主授权读取，不要求成员授权自己的网易云账号。彻底移除全网搜索歌曲与直接点歌能力，歌曲由成员从已分配来源逐首点入公共歌单，或由房主通过「随机点歌」从已分配成员的歌单中抽选。

候选读取与分配校验须按来源类型判断：收藏来源仍须有效且保持收藏，自建歌单（含私密）和「我喜欢」不套用「他人创建且已收藏」限制；所有来源均须通过房主当前授权有效读取。既有公共歌单目标冲突与成员权限校验继续适用。

这一取舍放弃了成员在点歌台内自主创建专用歌单、全网搜索存歌与修改来源歌曲的能力，免去为成员主动创建和清理专用云端资源的复杂性。来源在成员退出、被移除、解除分配、更换或删房时仅解除本地关联与快照引用，不调用网易云接口删除来源歌单或取消收藏；点歌台新建的公共专用歌单仍按原规则随房间删除清理。

来源扩展规格与验收记录见 [spec](../../.scratch/owner-assigned-favorite-playlists/spec.md) 及 [工单 04](../../.scratch/owner-assigned-favorite-playlists/issues/04-expand-owner-assigned-sources.md)。真实网易云授权下「我喜欢」及私密歌单的读取仍待验收。
