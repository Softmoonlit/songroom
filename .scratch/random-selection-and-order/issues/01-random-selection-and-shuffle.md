# 01：不区分新旧随机选歌并打散整组顺序

**What to build:** 房主随机点歌时，从成员个人歌单中不区分新旧随机抽选，再对选中整组歌曲洗牌。即使全部候选歌曲已在点歌台中，也可预览并确认；最终按网易云实际读回顺序展示，不承诺成员交错。

**Blocked by:** 无，可立即开始；可与工单 02 独立推进。

Status: resolved

- [x] 移除新歌优先及无新歌拒绝条件，不要求本轮至少包含一首当前点歌台不存在的歌曲。
- [x] 保留已有总数选择与默认值、成员尽量均分、余数随机分配、歌曲 ID 全房间去重、交叉候选调整归属及候选不足重分配规则。
- [x] 保留未配置或空来源不参与、已配置来源读取失败整次不换及来源有效性核验。
- [x] 确定歌曲及来源成员后对整组洗牌，不保证成员交错，允许同一成员的歌曲相邻。
- [x] 同一次预览及其确认使用同一目标清单与来源归属，执行中不重新抽选或洗牌。
- [x] 预览及结果文案不再承诺新歌优先、必须有新歌或预览即最终云端顺序；页面按云端实际顺序展示。
- [x] 使用可控随机源验证旧歌全部可选、均分与余数、交叉重复、来源归属、候选不足及整组洗牌，不依赖重复碰运气的测试。
- [x] 完成受影响页面及操作回归、类型检查和必要审查，不引入旧规则兼容分支。
