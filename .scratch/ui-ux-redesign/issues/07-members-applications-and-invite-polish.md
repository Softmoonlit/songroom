# 07: 房间成员列表重构与审批/邀请体验收敛

**What to build:** 房间成员界面彻底以成员列表为主体，把舞台还给室友列表；将原本大肆霸占顶部的房间邀请面板收敛为右上角「+ 邀请室友」按钮，点击弹出优雅的邀请码/链接复制弹窗；待审批加入申请平时完全隐形，仅在有新申请时在列表顶部浮现轻量通知横幅，点击呼出抽屉处理并伴随即时动画反馈；室友加入页面提供沉浸式邀请函卡片，申请跟踪页采用进度时间轴，房主审批通过后自动感知并伴随动画进入房间。

   - 移除常驻顶部的审批展开面板与底部的常驻大号邀请卡片，成员列表升级为第一视觉主体。

   - 平时无待处理申请时完全隐形；仅在房主具权且有待审批申请时在成员列表上方浮现轻量通知横幅（带呼吸脉冲动效），点击呼出 `ApplicationsDrawer` 右侧抽屉。

   - `JoinPage` 升级为居中卡片化「房间加入邀请函」，支持大字号输入邀请码、查验房间信息、已是成员或已有申请友好提示，以及拟用昵称提交。
   - `ApplicationPage` 升级为 3 步进度时间轴（提交申请 -> 房主审批 -> 进入房间），展示不同终结状态说明与重新申请入口；在审批通过后自动感知获批状态并伴随成功微动效平滑跳转进入房间，同时提供手动进房主按钮。
