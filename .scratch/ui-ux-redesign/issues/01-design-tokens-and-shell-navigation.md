# 01: 全局设计系统规范与 Shell 导航/基础文案降噪

**What to build:** 建立专业声学调色板、景深阴影、微光边框、严谨字阶与等宽数字（tabular-nums）全局设计规范体系；重构全局 Header 导航，移除已登录状态下重复的“我的房间”文字链接，将其升级为集成账号设置与退出登录的紧凑用户身份胶囊；将 Header 上的大号服务状态徽章弱化为极简指示点；账号设置页面补齐直达房间列表的返回导航，清除机制说教并实施模块化分区卡片，为全站按钮和交互元素赋予触感按压与悬停反馈。

**Blocked by:** None (can start immediately)

**Status:** need-review

- [x] 确立统一的现代调色板、微弱环境阴影、微光边框、字阶与 tabular-nums 设计变量；
- [x] 顶部导航栏移除已登录状态下的“我的房间”链接，改用紧凑优雅的用户操作胶囊；
- [x] Header 上的服务状态指示降级为微型状态指示点，不在正常运行时抢占视觉焦点；
- [x] 账号设置页面顶部提供清晰直观的返回导航，消除单向死胡同；
- [x] 账号设置页移除“同一时间只绑定一个账号...”等大段系统机制说教，按个人信息与密码安全清晰分区；
- [x] 全站按钮与交互元素具备平滑过渡、悬停反馈与 `:active` 触感按压形变；
- [x] 基础单元测试与编译检查通过。

## Comments

### 规划与立项
经 Grilling 与 to-tickets 批准确立，作为 UI/UX 重构的基础切片启动。

### 实现与验证 (Ticket 01)
1. **设计规范注入**：在 `styles.css` 建立现代中性调色板、声学 Indigo 强调色、微弱景深阴影 (`--shadow-xs` 至 `--shadow-xl`)、微光边框、字阶体系与 tabular-nums 等宽数字，配置轻量 `:active` 缩放触感。
2. **Header 导航重构**：
   - 移除已登录状态下重复且抢占视觉的“我的房间”链接；
   - 引入 `UserCapsule` 用户胶囊（首字母徽章 + 用户名 + 下拉菜单直达账号设置与退出登录）；
   - 将 `HealthStatus` 优化为无障碍微型圆点指示灯，默认正常状态静音、异常状态提示并维持无障碍提示。
3. **账号设置降噪**：
   - 顶部增加直达“返回房间列表”的返回链接；
   - 移除账号唯一性与重复性的大段文字说明，拆分为“个人资料”与“修改密码”两个模块化卡片；
   - 移除网易云绑定处的“绑定后全部房间共用授权”说明，优化表单占位符。
4. **验证结果**：
   - `pnpm typecheck`：通过；
   - `pnpm test`：全部 37 个测试文件、370 个单元测试通过；
   - `playwright test`：全部 127 个 E2E 测试（含 320px/900px/1440px 视口及 axe-core 无障碍合规性）全数通过。
