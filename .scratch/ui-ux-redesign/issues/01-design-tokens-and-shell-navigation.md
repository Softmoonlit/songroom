# 01: 全局设计系统规范与 Shell 导航/基础文案降噪

**What to build:** 建立专业声学调色板、景深阴影、微光边框、严谨字阶与等宽数字（tabular-nums）全局设计规范体系；重构全局 Header 导航，移除已登录状态下重复的“我的房间”文字链接，将其升级为集成账号设置与退出登录的紧凑用户身份胶囊；将 Header 上的大号服务状态徽章弱化为极简指示点；账号设置页面补齐直达房间列表的返回导航，清除机制说教并实施模块化分区卡片，为全站按钮和交互元素赋予触感按压与悬停反馈。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 确立统一的现代调色板、微弱环境阴影、微光边框、字阶与 tabular-nums 设计变量；
- [ ] 顶部导航栏移除已登录状态下的“我的房间”链接，改用紧凑优雅的用户操作胶囊；
- [ ] Header 上的服务状态指示降级为微型状态指示点，不在正常运行时抢占视觉焦点；
- [ ] 账号设置页面顶部提供清晰直观的返回导航，消除单向死胡同；
- [ ] 账号设置页移除“同一时间只绑定一个账号...”等大段系统机制说教，按个人信息与密码安全清晰分区；
- [ ] 全站按钮与交互元素具备平滑过渡、悬停反馈与 `:active` 触感按压形变；
- [ ] 基础单元测试与编译检查通过。
