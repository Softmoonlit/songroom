# 04: 公共歌单与歌曲列表体验重构（全屏聚焦与信息降噪）

**What to build:** 拆除包围公共歌单的大号外层卡片，收拢网易云 ID、长串同步时间等底层技术信息，使歌曲列表占据 80% 以上的第一视觉。消除暴露内部机制的“更新状态”与“刷新歌单”双按钮混淆，合并为单一的“同步歌单”操作，通过旋转指示与 SSE 自动感知最新状态。升级虚拟滚动歌曲列表排版，强化序号、歌曲名与歌手专辑层次，在每首歌曲右侧直观展示带昵称的点歌人胶囊徽标，并提供高质感空歌单引导。

**Blocked by:** 02: 房间工作台双栏居中布局与移动端导航

**Status:** ready-for-agent
