# 02: 房间工作台双栏居中布局与移动端导航

**What to build:** 彻底废除房间工作台中粗暴的绝对/固定定位侧栏，重构为现代两栏应用布局。左侧提供固定宽度吸附侧边栏，承载返回列表、房间名称、当前角色徽章与垂直功能切换；右侧主工作区内容容器限定最大宽度并严格自适应居中，彻底消除宽屏下内容严重偏左与留白失调问题。移动设备自适应为底部固定导航栏，进入房间后核心第一视口直接呈现内容。

**Blocked by:** 01: 全局设计系统规范与 Shell 导航/基础文案降噪

**Status:** ready-for-agent

- [ ] 废除固定定位与硬编码边距侧栏，重构为标准弹性双栏结构；
- [ ] 左侧吸附侧边栏固定宽度，紧凑展示房间名、角色/昵称胶囊以及垂直导航项；
- [ ] 右侧主工作区内部容器限定最大宽度并自动外边距居中，实现核心视口对称居中展示；
- [ ] 在窄屏和移动设备上自适应为底部固定导航栏，契合大拇指操作热区，顶部仅保留紧凑房间信息；
- [ ] 移动端输入聚焦与软键盘展开时不破坏工作台布局与视口滚动；
- [ ] 基础单元测试与编译检查通过。
