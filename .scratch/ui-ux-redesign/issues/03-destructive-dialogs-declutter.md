# 03: 全站破坏性确认弹窗高信噪比重构

**What to build:** 重构全站基于 Radix AlertDialog 的确认弹窗体系，彻底消灭充斥全站的“4~8 条排比后果清单”、调试版本号与统计行。统一确立「动宾标题 + 核心单句风险 + 关键危险标签（如不可恢复、立即生效） + 明确动作按钮」的高信噪比警示范式，覆盖全站删除房间、退出房间、移除成员、重置邀请等所有破坏性确认场景，让用户在清晰感知核心风险的同时不再受长篇大论文案压迫。

**Blocked by:** 01: 全局设计系统规范与 Shell 导航/基础文案降噪

**Status:** resolved

- [x] 改造删除房间确认弹窗：精炼为核心不可逆警告与红色警示标签；
