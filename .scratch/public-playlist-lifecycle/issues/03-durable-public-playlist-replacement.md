# 03：持久执行公共歌单整组替换

**What to build:** 将房主确认的预览作为固定业务意图，可靠替换同一公共云端歌单的歌曲集合，保留来源歌单，区分完整成功、部分完成和结果未知。

**Blocked by:** 02/公平抽选与预览；既有持久操作、权威快照、未知写入恢复及个人来源必要依赖。

**Status:** resolved

规格：[个人歌单与房主随机换歌](../spec.md)。阻塞项未解除前不启动实现。

## 验收清单

- [x] 确认命令只接受房主自己的有效预览，以固定歌曲集合及幂等键受理；同内容返回原操作，异内容及过期键拒绝，不重新抽选。
- [x] 受理与执行前校验房主、来源成员、个人绑定及授权、选中歌曲仍在、公共绑定和目标可写性；预览公共集合或顺序变化拒绝并要求重做预览。
- [x] 与公共点歌及保留的下一首重排能力按同一真实目标协调；执行和待确认期间禁止新冲突写，保留原账号串行、单成员操作及队列限制，不能因页面按钮隐藏而漏掉后端仍可受理的重排冲突。
- [x] 用 SQLite 保存必要步骤和原目标证据，发送边界持久化；不建立临时全局状态或独立调度器，不引入废弃计时清理路径。
- [x] 保留目标集合中已有歌曲；先逐首增加并确认缺少的新组歌曲，再逐首移除不在新组的旧歌曲；每写后完整读回，不删重建歌单，不额外排序。
- [x] 旧歌曲包括手动点歌，受理确认覆盖用户所见范围；不把预览之后的新点歌悄悄纳入删除。
- [x] 发送后中断、超时或读回矛盾时只读确认、不重发；未知时暂停后续删除，沿用有界补查与管理员处置，不自动回滚已确认写入。
- [x] 部分成功或外部变化时展示云端实际集合及已确认步骤；不能因添加或移除部分成功显示“已换好”，也不能声称旧歌单原封不动。
- [x] 最终完整读回目标集合后确认云端结果；随机歌曲新增本次抽选来源成员的去重点歌人标签，新加入与原有保留的选中歌曲规则一致，保留原有标签。使用与手动点歌相同的标签及展示，不自动加房主或其他仅拥有该歌曲的成员标签，标签处理失败单独反馈。
- [x] 持久保存经服务端验证的逐曲来源成员映射；重试和恢复不更换来源归属，记录标签前确认歌曲云端存在及来源成员、绑定有效，成员撤权不回写其标签。
- [x] 未移除的歌曲保留原有标签，确认移除清除标签；来源个人歌单内容与顺序均不受影响。
- [x] 授权失效、换号、成员退出、解绑、删房及重启沿用现有隔离和恢复；终结后清理最小恢复载荷，不新增换歌历史。
- [x] 持久操作及 HTTP 集成测试覆盖幂等、越权、冲突、每一步发送后崩溃、读回失败、部分成功、外部修改、撤权及标签结果。

## Comments

### 立项

随机换歌是多次上游写入，不能承诺原子替换。规格采用先补齐新组再移除旧组的执行顺序，并继承未知写入只确认不重发的现有约束。标签规则已由用户最终修订为按本次抽选来源成员添加，与手动点歌使用同一种标签；此前无个人标签规则已作废。解除标签设计阻塞，仍须满足上列实现依赖。本票尚未实现或验证，不构成实际生产歌单写入授权。

### 实现与验证

1. **实现说明**：
   - 新增 `public_playlist_replacement` 数据表及迁移 `0023_public_playlist_replacement.sql`，更新 schema 版本为 24。
   - 实现 `PublicPlaylistReplacement` 持久操作状态机：通过 `UpstreamScheduler` 串行执行网易云写入，支持严格幂等受理与重放。
   - 写入顺序为：逐首增加缺失的目标歌曲并读回核实 -> 逐首移除多余的旧歌曲并读回核实 -> 严格核对最终云端集合 -> 针对有效来源成员写入去重点歌人标签 -> 终结。
   - 发送边界持久化：若在发送中出现中断、超时或应用崩溃，绝不重复重发写入；重启或补查后仅通过 `playlistDetail` 只读读回核对，支持 5s/30s/120s 三轮有界补查。
   - 目标冲突协调：与公共点歌 `requestPublicSong` 以及 `playNext` 互斥，执行及待确认期间阻止冲突写操作。
   - 终结清理：操作达到终态后清理 `targetTracks`、`originalSongIds` 和 `sources` 等恢复载荷，仅保留最小防重记录与目标数量统计。
   - 暴露 HTTP 路由：`POST /api/rooms/:roomId/public-playlist/random-replacement` 及 `GET /api/rooms/:roomId/public-playlist/random-replacement/:operationId`。

2. **验证结果**：
   - 单元与持久操作测试：`apps/songroom/src/operations/public-playlist-replacement.test.ts` 12 项测试全部通过，覆盖房主鉴权、幂等受理与冲突、目标互斥、增删读回、超时不重发与补查、外部修改中止、来源换绑与撤权不回写标签、发送中崩溃重启恢复、终结载荷清理及房间解散级联清理。
   - HTTP 接口测试：`apps/songroom/src/http/public-playlists.test.ts` 覆盖随机换歌确认与轮询接口鉴权、参数校验、幂等受理与结果查询。
   - 全量回归测试：全套 49 个测试套件、471 项测试全部通过，TypeScript 类型检查无报错。
