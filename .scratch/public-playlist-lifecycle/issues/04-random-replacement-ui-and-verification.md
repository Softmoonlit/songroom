# 04：接入随机换歌界面与完整验收

**What to build:** 在个人歌单基础能力上接入房主“随机换一组”、预览确认和持久操作反馈，让成员看到真实公共快照，并准确表达客户端重新载入的边界。

**Blocked by:** 02/公平抽选与预览；03/持久整组替换；05/仅移除下一首播放按钮；既有个人歌单工单 24/25/26/28 及其必要生命周期依赖。

**Status:** need-review

规格：[个人歌单与房主随机换歌](../spec.md)。阻塞项未解除前不启动实现。

## 验收清单

- [x] 按既有规划接入可选个人歌单入口：室友主动新建，房主选择已有自建或收藏来源；未配置仍可直接公共搜索点歌。
- [x] 个人歌单只允许本人维护，收藏只读，本人来源逐首点歌与房主跨成员随机换歌权限清晰分离；成员详情仍可只读查看。
- [x] 房主公共歌单页显示“随机换一组”，选择 5/10/15/20 首，默认 10；其他成员不显示换歌操作，接口同样拒绝越权。
- [x] 随机歌曲按本次抽选来源成员显示点歌人昵称，复用手动点歌标签和筛选，不增加随机来源专用样式；原有保留歌曲标签继续保留，同一成员去重，手动再点正常增加标签。
- [x] 预览先展示所选歌曲、各成员贡献、实际数量、旧歌曲与带成员标签歌曲数，确认文案说明会替换全部旧歌曲。
- [x] 退出预览不写云端，确认后禁止重复生成写入；预览失效或公共歌单变化时更新并要求重新预览。
- [x] 页面正确展示处理中、待确认、失败及部分完成，刷新和切页后查询原操作，不能把浏览器预览作为已确认公共快照。
- [x] 成功后同步真实公共歌曲及位置，提示房主在网易云客户端重新载入歌单并点“播放全部”，不宣称网站已更新客户端当前队列。
- [x] 不增加每日清空、播完删除、计时和自动续期入口；仅移除歌曲行下一首播放按钮，保留现有后台重排能力、旧操作结果查询、公共搜索点歌、播放指示与定位、移动端布局。
- [x] 浏览器测试覆盖房主/室友、空个人来源、读取失败、预览取消/失效、换歌确认、跨页面恢复、并发点歌冲突、来源不变和部分完成反馈。
- [ ] 仅在明确授权的专用测试歌单进行真实网易云验收，核对同一歌单 ID 的最终歌曲集合、实际顺序、来源不变及官方客户端重新载入行为；未完成真实验收时保留 need-review。
- [x] 交付更新本票验收清单、状态、实现提交、实际验证结果和剩余事项；不能以规划或模拟测试宣称生产已验收。

## Comments

### 立项

产品选择采用房主主动换歌，保留现有客户端播放全部的人工环节，取消所有自动删除方案。01 设计决议已解决，完整规格定稿；解除设计信息阻塞，仍须满足上列实现依赖。本文仅拆分待实现工作，尚未修改业务代码或执行云端操作。

### 实现与自动化验证

1. **界面与交互接入**：
   - 在 `PublicPlaylistPane.tsx` 的头部操作区，根据服务端 `allowedActions.includes("replacePublicPlaylist")` 展示「随机换一组」按钮（仅房主可见且可点击，在未绑定、无权或操作执行中时禁用）。
   - 封装 `RandomReplacementDialog.tsx`，支持 5/10/15/20 首选项（默认 10 首）、重新抽选、抽选概况（实际首数与不足说明、替换全部旧歌范围与带标签数、各成员均分贡献列表、候选歌曲详情与来源成员标签和新歌标识）。
   - 确认替换采用 `idempotencyKey` 机制，网络抖动或失败重试时复用当前预览的幂等键，避免重复生成写操作；退出或取消预览绝不发送任何写请求。
   - 实现 `random-replacement-messages.ts`，为 `NO_NEW_SONGS`、`EMPTY_CANDIDATES`、`PREVIEW_INVALIDATED`、`ACCOUNT_PAUSED`、`PLAYLIST_CONFLICT` 等业务错误提供准确温和的中文反馈；同时提供各步骤的进度文案（添加/移除歌曲数量、核验与打标）。
   - 公共歌单状态卡片无缝支持操作轮询、跨页（切换到我的歌单/成员详情）及刷新恢复，失败或停止卡片提供关闭按钮，不永久锁定换歌入口。
   - 成功后提示房主在网易云客户端重新载入歌单并点“播放全部”，公共快照刷新后歌曲带有来源成员点歌人昵称，并可在点歌人筛选中按成员过滤。

2. **样式与无障碍合规**：
   - 增加 `.random-replacement-modal`、`.random-count-selector`、`.random-stats-card`、`.random-preview-tracks-list`、`.replacement-status-banner` 等样式。
   - 严格保证颜色对比度（如标签与高亮按钮对标 WCAG AA 4.5:1+），为滚动清单增加 `tabIndex={0}` 以支持键盘无障碍导航。
   - 经 AxeBuilder 扫描，320px、390px、1440px 视口下无任何 a11y violations，亦无横向滚动条溢出。

3. **测试验证结果**：
   - 单测：`pnpm test` 全站 50 个套件、482 个测试用例全部通过（含新加入的 `random-replacement-messages.test.ts`）。
   - E2E 浏览器测试：`pnpm test:e2e` 全站 172 个用例全部通过，其中 `tests/e2e/random-replacement.spec.ts` 13 个用例覆盖：
     - 权限边界（房主展示入口、室友隐藏入口且接口拒绝越权）
     - 默认 10 首预览生成、切换首数与重新抽选
     - 详尽预览信息展示与客户端播放全部说明
     - 退出/取消预览无任何云端写操作
     - 候选异常（NO_NEW_SONGS、EMPTY_CANDIDATES、MODULE_ERROR）反馈
     - 完整确认与持久操作推进、成功提示、来源成员点歌人标签及筛选联动
     - 部分完成与失败进度展示
     - 跨页面切换与刷新恢复持久操作
     - 预览失效保护（PREVIEW_INVALIDATED 要求重新预览）
     - 相同幂等键重试防御
     - 已配置来源读取失败整次不换
     - 并发写冲突与操作超限防御
     - 320px/390px/1440px 多视口与 Axe 基础无障碍合规
