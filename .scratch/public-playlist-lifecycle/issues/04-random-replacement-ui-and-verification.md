# 04：接入随机换歌界面与完整验收

**What to build:** 在个人歌单基础能力上接入房主“随机换一组”、预览确认和持久操作反馈，让成员看到真实公共快照，并准确表达客户端重新载入的边界。

**Blocked by:** 02/公平抽选与预览；03/持久整组替换；05/仅移除下一首播放按钮；既有个人歌单工单 24/25/26/28 及其必要生命周期依赖。

**Status:** ready-for-agent

规格：[个人歌单与房主随机换歌](../spec.md)。阻塞项未解除前不启动实现。

## 验收清单

- [ ] 按既有规划接入可选个人歌单入口：室友主动新建，房主选择已有自建或收藏来源；未配置仍可直接公共搜索点歌。
- [ ] 个人歌单只允许本人维护，收藏只读，本人来源逐首点歌与房主跨成员随机换歌权限清晰分离；成员详情仍可只读查看。
- [ ] 房主公共歌单页显示“随机换一组”，选择 5/10/15/20 首，默认 10；其他成员不显示换歌操作，接口同样拒绝越权。
- [ ] 随机歌曲按本次抽选来源成员显示点歌人昵称，复用手动点歌标签和筛选，不增加随机来源专用样式；原有保留歌曲标签继续保留，同一成员去重，手动再点正常增加标签。
- [ ] 预览先展示所选歌曲、各成员贡献、实际数量、旧歌曲与带成员标签歌曲数，确认文案说明会替换全部旧歌曲。
- [ ] 退出预览不写云端，确认后禁止重复生成写入；预览失效或公共歌单变化时更新并要求重新预览。
- [ ] 页面正确展示处理中、待确认、失败及部分完成，刷新和切页后查询原操作，不能把浏览器预览作为已确认公共快照。
- [ ] 成功后同步真实公共歌曲及位置，提示房主在网易云客户端重新载入歌单并点“播放全部”，不宣称网站已更新客户端当前队列。
- [ ] 不增加每日清空、播完删除、计时和自动续期入口；仅移除歌曲行下一首播放按钮，保留现有后台重排能力、旧操作结果查询、公共搜索点歌、播放指示与定位、移动端布局。
- [ ] 浏览器测试覆盖房主/室友、空个人来源、读取失败、预览取消/失效、换歌确认、跨页面恢复、并发点歌冲突、来源不变和部分完成反馈。
- [ ] 仅在明确授权的专用测试歌单进行真实网易云验收，核对同一歌单 ID 的最终歌曲集合、实际顺序、来源不变及官方客户端重新载入行为；未完成真实验收时保留 need-review。
- [ ] 交付更新本票验收清单、状态、实现提交、实际验证结果和剩余事项；不能以规划或模拟测试宣称生产已验收。
