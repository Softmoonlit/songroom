# 02：实现公平随机选歌与只读预览

**What to build:** 房主按全房间总首数生成一组按成员尽量均分的随机歌曲，预览来源贡献及旧歌曲替换范围，预览阶段不写云端。

**Blocked by:** 既有个人歌单工单 24、25 及来源快照、解绑与资源清理的必要依赖。

**Status:** resolved

规格：[个人歌单与房主随机换歌](../spec.md)。阻塞项未解除前不启动实现。

## 验收清单

- [x] 仅当前房主可生成和确认本房间随机预览，来源为房间当前已配置个人歌单的成员，包含只读收藏来源；不扩大普通成员的逐首点歌权限。
- [x] 支持全房间总数 5/10/15/20，默认 10；按成员尽量均分，余数及平局随机，成员多于目标数时随机参与。
- [x] 每位成员内随机选新歌优先，不足选旧歌；全房间按歌曲 ID 去重，成员候选不足重分配，整体不足显示实际数量。
- [x] 公平分配在歌曲 ID 唯一约束下成立，交叉重复允许调整候选及归属；A={X}、B={X,Y}、目标 2 首时得到 A=X、B=Y，不能贪心耗尽 A 的唯一候选后宣称其来源不足。
- [x] 没有新歌时不换；候选有新歌时最终预览包含新歌，不为追求变化降低已经可以达到的成员均分程度。
- [x] 未配置或有效空歌单不参与；任何已配置来源读取失败整次不换，保留旧公共歌单，不凭旧快照略过来源。
- [x] 通过现有调度读取完整来源与当前公共歌单，保存预览依据；不写来源、不排序公共歌单、不发任何歌曲增删请求。
- [x] 预览展示具体歌曲、成员贡献、实际总数、旧歌曲总数及其中带成员点歌标签的歌曲数；退出预览不改变歌单。
- [x] 服务端验证预览归属和固定歌曲集合、逐曲来源成员映射，后者决定确认后新增的点歌人标签；客户端不能任意替换歌曲、成员或来源，确认与恢复不更换归属；过期、权限变化、丢失或重启后重新预览。
- [x] 抽样使用现有依赖或 Node 原生随机能力，不加通用随机框架；测试使用可控随机源验证边界，不用统计碰运气代替正确性断言。
- [x] 公开接口及模块测试覆盖公平分配、少于成员数、交叉重复、候选耗尽、新旧取舍、读取失败、越权、取消无写和失效预览。

## Comments

### 立项

根据已逐轮确认的数量、成员均分、随机来源及预览确认规则拆出。01 设计决议已解决，完整规格定稿；解除设计信息阻塞，仍须满足上列既有依赖。本票未实现，不能将清单视为已验证能力。

### 实现与验证

1. **核心算法**：实现 `selectFairRandomTracks` 纯函数模块（`apps/songroom/src/operations/random-selector.ts`），涵盖成员均分、目标配额下二分图增广重排非贪心交叉归属、新歌优先与不足旧歌补充、全局无新歌拒绝换歌（`NO_NEW_SONGS`）、新歌保底与均分保护、候选去重与不足重分配。
2. **预览服务**：实现 `PublicRandomPreview`（`apps/songroom/src/operations/public-random-preview.ts`），通过房主鉴权、既有上游调度读取公共歌单与全部已配置成员个人歌单（任何失败则整次熔断）；内存短命记录（TTL 10分钟）保存固定歌曲列表、逐曲来源归属映射以及全部来源绑定依据（包含各来源 bindingId、generation、snapshotVersion、songIds）；提供 `get` 与 `validate`，在过期、快照变化、成员退出或候选歌曲移除时准确判定失效。
3. **接口端点**：实现 `POST /api/rooms/:roomId/public-playlist/random-preview` 与 `GET /api/rooms/:roomId/public-playlist/random-preview/:previewId`，严格校验 5/10/15/20 选歌数量及会话房主权限。
4. **验证覆盖**：
   - 算法测试（`random-selector.test.ts`）：10 个用例覆盖余数分配、大于成员数、交叉候选增广重排、新歌优先、旧歌填充、确定性伪随机等；
   - 服务测试（`public-random-preview.test.ts`）：7 个用例覆盖房主鉴权、完整统计、只读零写验证、来源失败熔断、过期失效、快照与来源变更失效判定等；
   - 路由测试（`public-playlists.test.ts`）：覆盖鉴权、参数校验与预览只读读取。
   - 全库 48 个测试文件、458 个用例全部通过，TypeScript 编译检查 0 错误。
5. **剩余事项**：后续由工单 03 实现随机替换的持久操作、二次确认与上游歌曲增删提交。
