# 个人歌单与房主随机换歌

Status: resolved

## 目标与当前状态

成员以个人歌单长期存歌，房主在想换内容时，预览并确认一组按成员尽量均分的随机歌曲，用其替换公共歌单当前内容，再到网易云客户端点击“播放全部”。

本规格汇总用户逐轮确认的产品规则。随机换歌按本次抽选的来源成员添加点歌人标签，与成员亲自点歌使用相同标签及展示。目前全部相关工单（01 至 06）均已全部实现并通过完整验证与真实验收。讨论过程与决议验收状态见 [决议票](issues/01-decide-personal-library-and-public-cleanup.md)。

## 公共歌单与播放端

- 保留一份固定绑定的公共云端歌单，不因换歌删除或重建歌单本身。
- 当前歌曲一直保留，直到房主主动随机换歌或用户在网易云客户端操作；不按时间、播放记录、播放结束或跳过事件自动删除。
- 随机换歌替换全部旧公共歌曲，包括成员手动点入的歌曲。它不是追加歌曲，也不保留另一套本地歌曲顺序。
- 房主确认云端换歌完成后，在官方客户端重新进入或刷新对应歌单，并点击“播放全部”。网站不承诺官方客户端已经载入的播放队列自动更新。
- 仅移除歌曲行“下一首播放”按钮及其对应表头和空白列，保留现有前端操作逻辑、后端接口、云端重排能力和持久操作恢复，以便以后恢复入口；不做数据库退役或新增兼容层。已有未确认操作仍可查询原结果。该能力只重排云端歌单，不控制官方客户端队列。
- 移动端和桌面均将点歌人置于右侧独立列；移动端表头为“歌曲与歌手”“点歌人”，多个昵称在点歌人列内换行，不与歌曲信息混排。
- 保留只读播放指示和歌曲定位，继续按房主账号最近记录提供近似线索，不将其描述为指定客户端的实时状态。
- 取消此前讨论的每日清空、播放后移除、按数量计时、手动歌曲过期和续期设计；不为这些弃用方案新增表、设置或定时任务。

## 个人歌单

- 个人歌单是可选配置；未配置仍可通过直接搜索向公共歌单点歌，只是不参与随机换歌来源。
- 室友主动在房主当前网易云账号下创建本房间专用个人歌单，不要求室友授权自己的网易云账号；不在获批加入时自动创建。
- 房主可绑定当前账号已有的自建或已收藏普通歌单。自建来源按能力可维护，收藏来源只读，均可作为随机换歌来源；不复制或修改收藏来源。
- 延续现有规划中的“我的歌单”入口、个人来源快照、本人单首维护和本人来源逐首点歌。直接公共搜索点歌不自动写入个人歌单。
- 房主已有来源可在其自建房间共用，室友专用来源不跨成员或房间共用。解绑、成员退出、删房和授权变更继续遵守既有生命周期规则。
- 普通成员只可从自己的个人歌单逐首点歌；房主额外拥有本房间随机换歌的跨成员取歌权限，不获得编辑他人歌单或任意逐首选取他人来源的权限。
- 复用已有个人歌单工单 [24](../multi-room-song-request-mvp/issues/24-owner-personal-playlist.md)、[25](../multi-room-song-request-mvp/issues/25-roommate-personal-playlist.md)、[26](../multi-room-song-request-mvp/issues/26-single-track-personal-maintenance.md)、[28](../multi-room-song-request-mvp/issues/28-personal-source-song-request.md) 及其必要权限、解绑和资源清理依赖，不在本功能建立平行实现。批量导入、批量删歌等不因本规格额外扩大范围。

## 数量与随机选择

- 房主选择换歌后全房间合计首数：5、10、15、20，默认 10；不是每个成员分别选择这么多首。
- 来源包括本房间所有已配置个人歌单的当前成员，包含房主。未配置或有效空歌单不参与。
- 尽量均分成员贡献数量，成员均分优先于全房间新歌优先。每位成员份额内部优先随机选当前公共歌单没有的歌曲，不足再随机选自己的旧歌；不按个人歌单顺序取前几首。
- 例如 4 个可用成员选 10 首，可分配为 3、3、2、2；额外名额随机分配。成员数大于目标首数时，随机决定本次有名额的成员，不保存长期轮换历史。
- 成员均分必须在歌曲 ID 唯一的约束下实现，不能只按随机顺序贪心分配后就把成员判为不足。允许调整同一歌曲的来源归属或改选其他候选，以保持可达到的公平分配；例如 A 只有 X，B 有 X、Y，选择 2 首时应分为 A=X、B=Y，而不能因 B 先抽到 X 就变成 A=0、B=2。先确保可达到的成员均分，再在符合该分配的歌曲候选中按新旧偏好随机抽选。
- 全房间按网易云歌曲 ID 去重；同一歌曲在多个个人歌单中出现，也只加入一次，并只计入一次成员贡献。本次最终分配的来源成员同时作为该歌曲新增标签的归属，不给其他仅拥有同一歌曲的成员自动加标签。某成员的候选已经被其他成员选走时，继续查找该成员其他候选；无候选则将剩余机会交给其他可用成员。
- 若全部来源不足所选数量，使用实际可选数量并明确展示，不为凑数重复加入歌曲。
- 候选中没有任何公共歌单当前不存在的新歌曲时，提示“暂无新歌曲可换”，保留当前歌单。抽样结果必须包含至少一首新歌；若均分抽样本次全为旧歌但候选存在新歌，在不降低已达成成员均分程度的条件下，用某个获名额成员的新歌替换其旧歌；若所有有新歌成员均未获名额，则在同等配额的成员间随机调整一个名额，使结果包含新歌。
- 所有候选须来自当前有效权限和完整云端读取。任何已配置来源读取失败、目标失效或无法证明读取完整时，整次不换歌，保留当前公共歌单，提示具体来源问题；不把读取失败当作空歌单，也不凭旧快照略过该成员。
- 新组歌曲的排列以网易云实际读回为准，不额外调用整表排序接口来实现随机播放顺序。

## 预览与确认

- 公共歌单页仅向房主提供“随机换一组”，数量默认 10。
- 先完成来源读取及抽样，再展示新歌曲清单、各成员贡献数量、实际总数，以及将替换的旧歌曲总数和其中有成员点歌人标签的歌曲数。
- 预览不发出云端歌曲写入，不占据长期目标写锁。关闭或退出预览不改变云端歌曲，不保存跨设备草稿或换歌历史。
- 服务端必须能够验证确认命令引用的是该房主、房间、绑定及预览的同一组歌曲与逐曲来源成员，不能信任浏览器任意提交的歌曲列表或标签归属，也不能确认时重新抽另一组或更换来源归属。
- 预览为短命资源；过期、丢失或服务重启后应重新生成，不能静默恢复旧预览并覆盖当前状态。
- 点击“确认替换”后成为持久操作。关页、切页不取消已提交操作；使用同一幂等键重试只查询或返回原操作，不产生另一组歌曲或另一轮替换。
- 已提交后明确显示排队、处理中、结果待确认、明确失败、部分完成或完成；只有最终云端读回符合目标集合且相关标签处理完成，才能报告完整成功。

## 并发、权限与写入恢复

以下为沿用当前持久操作与快照规则的工程约束，不另设播放端协议。

- 确认与执行前重新核验房主身份、当前成员与个人绑定、来源权限和选中歌曲、房主授权、公共绑定及目标可写性。来源或成员配置变化导致预览依据失效时，应更新展示并重新预览，不静默换源或重新抽歌。
- 公共歌单歌曲集合或顺序与预览依据不同，拒绝本次替换并刷新；包括预览之后室友新点歌曲，避免覆盖房主未确认的新内容。
- 与现有公共点歌及保留的下一首重排能力按同一真实网易云账号加歌单 ID 协调。预览阶段允许正常点歌；确认后及替换/待确认期间，拒绝新的冲突写操作并提示当前换歌未结束，不让新点歌或重排插入替换过程。
- 原有单成员同房间最多一个未完成写操作、账号有界队列、每账号串行及全站并行上限继续适用。不建立独立 worker 或第二套调度器。
- 服务端持久保存本次目标歌曲集合、原公共依据与必要执行步骤；用现有单曲写入能力逐首处理，每次写后读取实际状态，不宣称网易云支持原子整组替换。
- 公共歌单中已经选入新组的歌曲保留，先加入缺少的新组歌曲并确认，全部目标歌曲均确认存在后，再逐首移除不属于新组的旧歌曲；不先清空再尝试补入，也不删除重建公共歌单。
- 任何可能已发送的写入结果未知时，只读补查并暂停后续破坏性步骤，不自动重发、不自动回滚、不换另一组来掩盖结果。补查、重新授权与管理员收口沿用现有恢复约束。
- 明确失败或外部并发导致无法完整替换时，展示云端实际集合与已确认进度，区分未开始、已添加但尚未移除、部分移除及结果待确认，不谎称旧歌单完全保留或替换已完成。
- 网易云外部客户端不受本地锁控制；读回出现未预期歌曲或外部变化时停止自动删除、展示最新状态，不反复覆盖争夺目标集合。
- 随机选中歌曲按本次最终抽选归属添加来源成员的点歌人标签，与本人手动点歌使用同一种标签、昵称展示和筛选，不额外区分来源标记。新加入与原有保留的选中歌曲都遵循此规则；已有真实标签继续保留，同一成员标签去重，不因房主发起操作自动给房主加标签。歌曲云端存在已确认且来源成员资格、绑定有效后才记录对应标签；确认移除的旧歌曲清除全部标签，标签处理失败与云端结果分别反馈，不提前显示完整成功。
- 撤权、解绑、换号、删房及重启继续遵守旧结果隔离。未发送步骤可停止；可能已发只查明原目标，不利用新账号授权写旧目标。
- 终结后清除用于换歌恢复的歌曲输入等数据，按既有规则保留最小防重记录；不新增长期换歌历史。

自动化应覆盖实际公开接口与持久状态变化：成员公平、余数、人数多于首数、候选不足、交叉重复、新歌优先、纯旧歌拒绝、读取失败不写、越权、预览失效、确认幂等、同目标冲突、每一步读回、发送后中断、部分成功、授权与成员变化、标签及客户端真实边界。抽样测试应注入可控随机源，不能依靠重复运行碰运气判断通过。

浏览器验收覆盖数量选择、预览各成员贡献、替换提示、取消预览无写、确认后操作恢复与异常展示。真实网易云验收仅在明确授权的专用测试歌单进行，验证保留同一歌单 ID、完整歌曲集合、实际顺序及来源不变；模拟测试不代替该项验收。
