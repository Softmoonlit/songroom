# 03: 适配未分配状态与随机点歌成员门槛，完成全量 E2E 回归

**What to build:** 适配成员在「我的歌单」中的未分配引导与失效告警，适配点歌台「随机点歌」的参与成员门槛，复用既有快照浏览、逐首点歌与随机替换能力，并完成全链路的自动化端到端测试与回归验收。

**Blocked by:** 02/房主在房间成员页分配、更换与解除收藏歌单

**Status:** ready-for-agent

- [ ] 室友在「我的歌单」处于未分配状态时，展示提示“房主尚未为你分配歌单，请联系房主分配”。
- [ ] 房主在「我的歌单」处于未分配状态时，展示提示“你尚未为自己分配歌单”，并提供「前往分配」按钮，点击直接切换至房间成员页并引导分配。
- [ ] 已分配成员在「我的歌单」中可正常浏览歌曲快照，歌单内过滤搜索正常，点击单曲「点歌」成功将歌曲加入公共歌单并记录本人标签。
- [ ] 若绑定的收藏歌单在外部失效（被作者删除或被房主取消收藏），「我的歌单」顶部展示黄色失效告警 Banner，并保留最后一次成功快照。
- [ ] 点歌台发起「随机点歌」时，抽选成员弹窗中仅已分配歌单的成员可勾选，未分配成员置灰禁用并标注“未分配歌单”。
- [ ] 多成员绑定同一歌单时，随机点歌均分抽选、去重打散及来源成员标签写入正常。
- [ ] 成员退出房间或房主删除房间时，仅清除本地关联，外部网易云歌单不被取消收藏或删除。
- [ ] 编写并执行全量 Playwright E2E 自动化测试，验证导航默认页、无障碍（Axe）、全视口（320px/900px/1440px）响应式无溢出及全套业务流程，测试全部通过。
