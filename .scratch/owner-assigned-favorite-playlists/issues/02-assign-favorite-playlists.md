# 02: 房主在房间成员页分配、更换与解除收藏歌单

**What to build:** 让房主能够在房间成员列表中为每位成员（包括自身和室友）统一管理点歌来源：拉取房主已授权账号下的网易云收藏歌单（排除自建歌单），支持为成员分配新歌单、更换已分配歌单或解除分配；支持多位成员共享绑定同一份收藏歌单，并保证室友端无法篡改分配。

**Blocked by:** 01/下线全网搜索与个人歌单自建/删除，收敛一级导航

**Status:** ready-for-agent

- [ ] 调整 `personal_playlist_binding` 数据结构，移除 `target_unique` 索引，允许多个成员绑定同一个网易云收藏歌单。
- [ ] 新增房主专属候选接口，分页拉取网易云歌单并严格过滤为收藏歌单（`subscribed === true && creatorId !== accountId && status === 0`），排除自建歌单。
- [ ] 新增房主专属的分配、更换与解除分配持久命令与 HTTP 接口，非房主调用严格返回 403 Forbidden。
- [ ] 「房间成员」列表中，房主在未分配成员行看到「分配歌单」按钮，在已分配成员行看到「更换歌单」与「解除分配」操作，不显示歌单名称文本。
- [ ] 点击分配/更换弹出模态框展示收藏歌单卡片（封面、歌名、曲目数、原作者），选中确认后完成绑定并写回本地快照；若无收藏歌单显示友好空状态引导。
- [ ] 室友打开「房间成员」列表保持纯只读，不显示任何分配、更换或解除操作按钮。
- [ ] 单元与集成测试覆盖候选过滤、权限拦截、多成员同绑、解绑与更换操作幂等性。
