# 01: 下线全网搜索与个人歌单自建/删除，收敛一级导航

**What to build:** 从房间中彻底移除全网搜索歌曲与直接点歌能力，下线搜索独立页面，将房间一级导航收敛为「点歌台」、「我的歌单」、「房间成员」、「房间设置」四个标签页，并默认激活「点歌台」；同时从「我的歌单」和后台中清理专用歌单自建弹窗、单首删除接口及成员/删房时的云端歌单清理任务，消除多余的非核心路径。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 房间一级导航展示为「点歌台」、「我的歌单」、「房间成员」、「房间设置」4 个标签页，移除「搜索歌曲」标签页。
- [ ] 每次进入房间默认展示「点歌台」，不记忆上一次停留的标签页。
- [ ] 移除 `SongSearchPane` 及 `/api/rooms/:roomId/song-search` 后端接口，点歌台不展示全网搜索点歌入口或抽屉。
- [ ] 从「我的歌单」中移除自建专用歌单弹窗，移除歌曲行上的单首删除按钮。
- [ ] 下线服务端专用个人歌单创建（`createPersonalPlaylist`）与单首删除（`personal_song_mutation`）接口与持久操作。
- [ ] 成员退出房间或房主删除房间时，不再向网易云生成或执行任何个人歌单清理任务（Cleanup Task）。
- [ ] 单元与集成测试回归通过，无废弃接口引用错误。
