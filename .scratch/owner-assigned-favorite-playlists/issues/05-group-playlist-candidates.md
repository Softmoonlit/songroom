# 05: 选择歌单按来源分组显示标题与数量

Status: resolved

## 范围

房主分配或更换成员歌单时，候选按「我喜欢的音乐 → 自建歌单 → 收藏歌单」显示同级分组标题与数量，空组隐藏。组内保持网易云原顺序，各组共享一个单选列表。私密自建归入自建，单个候选只归属一组。

## 验收清单

- [x] 候选接口返回必填 `sourceType`，由后端分类，前端不根据名称推断。
- [x] 适配器保留网易云 `specialType`；房主自有且类型为 5 的来源归入「我喜欢的音乐」，其余自有归入自建，已收藏他人来源归入收藏。
- [x] 三个同级分组标题按确认顺序展示，并显示候选数量；空组隐藏，组内顺序保持不变。
- [x] 全部组共享单选状态，切换分组选择不会保留多份选中。
- [x] 测试覆盖改名不影响分类、同名普通歌单不误判、他人特殊歌单仍按收藏归类、数量和空组隐藏。
- [x] 类型检查、构建、定向业务及真实适配器离线测试、相关界面回归通过；复查未发现实际缺陷。
