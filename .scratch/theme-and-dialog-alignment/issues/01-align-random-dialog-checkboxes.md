# 01：歌单顶部按钮重排与随机点歌弹窗 Checkbox 居左对齐

**What to build:** 
1. 重排点歌台顶部操作按钮：房主主按钮「随机点歌」移至最左侧第一位，其后依次为「搜索」、「定位到正在播放」与「同步歌单」；重排我的歌单顶部为「搜索」→「同步歌单」；并优化移动端小屏响应式文字收缩（单行不折行）；
2. 优化随机点歌弹窗中的成员选择与全选布局，将“全选”复选框调整至列表项顶部居左对齐，使得全选 Checkbox 与下方每个成员的 Checkbox 在同一垂直线上严格对齐。

**Blocked by:** 无，规格已确认。

Status: resolved

规格：[随机点歌弹窗 Checkbox 居左与全站深色模式规格](../spec.md)。
