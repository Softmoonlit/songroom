# 歌单页面布局与点歌台交互调整

## 已确认规格

- 房间导航顺序为搜索歌曲、我的歌单、点歌台、房间成员、房间设置；进入房间默认搜索歌曲。
- 公共歌单在界面中称为“点歌台”，底层仍为房间公共网易云歌单，不更改云端已有名称及接口。
- 搜索结果添加按钮显示“添加到我的歌单”。
- 房主“随机换一组”改为紫色“随机点歌”，保留预览确认、整组替换和原抽选规则。
- 取消进入点歌台时自动同步网易云歌单；保留手动同步，随机点歌完成后自动更新列表。最近播放独立刷新、随机预览最新读取及点歌写后核验保留。
- 点歌台和我的歌单统一为左侧标题与歌曲数、右侧同步和搜索按钮、下方列表。点歌台在通用按钮后提供播放定位和随机点歌。
- 我的歌单新增歌名、歌手筛选，保留原始序号及本人点歌和删除操作；删除顶部云端名称、专用/可维护标识及同步时间。两个歌单的云端名称、ID 与快照时间统一在房间设置展示。
- 成员行不可点击，仅“查看歌单”按钮进入详情；详情继续提供本人改昵称和房主移除成员。
- 清理重复、常驻解释文案，保留权限限制、错误和结果待确认信息。

## 确认记录

用户已逐项确认同步边界、统一布局及成员按钮入口，授权实施。旧规格中的导航顺序和按钮文案由本规格覆盖。
