# 多房间点歌台决策地图

Label: wayfinder:map
Status: open

## Destination

形成可直接进入开发的多房间 MVP 产品与技术规格：统一点歌台账号、房主用户级网易云授权复用、每房间公共歌单与可选的成员个人歌单、个人歌单文本批量导入，以及成员直接搜索或从自己的个人歌单逐首公共点歌。

明确注册与邀请、权限、歌单生命周期、上游接口边界、快照同步、并发失败、安全运维、交互和验收条件；本努力只形成决策与规格，不开发正式应用。

## Notes

- 采用根目录 [CONTEXT.md](../../CONTEXT.md) 的术语。grilling 票使用 grilling 与 domain-modeling；prototype 票使用 prototype；系统架构票同时使用 codebase-design。
- 已确认的产品范围是多房间、可恢复账号、公共与个人歌单共存、房主用户级网易云授权复用。歌单创建、已有及收藏歌单绑定与清理规则以对应票据评论为准，未解决的权限与生命周期不视为已经确定。
- 云端歌曲与顺序是唯一权威，点歌台只维护快照及成员、标签等业务信息，不主动置顶或重排已有歌曲，不保留旧单房间方案的兼容路径。
- 账号与运维规则以[确定多房间安全、部署与运维边界](issues/06-decide-security-deployment-and-operations.md#解决评论安全部署与运维边界已确认)最终决议为准；前端自行设计，首版自用，账号采用组件默认策略，不额外设计认证安全机制，必要业务权限与恢复要求不取消。实际 Caddy/证书与资源核查属于部署前验收，不将规划完成视为已经上线。
- [宿舍点歌台决策地图](../dorm-song-request/map.md) 是旧单房间努力的历史记录。已有接口与安全调查可作为证据入口，但匿名成员、单一部署房主、房间独立授权和主动置顶不能直接沿用；旧未完成工作由本地图重新界定问题。
- 真实账号原型须与房主确认账号、专用测试歌单和操作范围，由房主扫码。[授权复用与共存实测](issues/04-verify-auth-reuse-and-client-coexistence.md#解决评论固定基线的小量实测通过)仅覆盖固定版本、隔离原型与低风险样本，不能代替正式应用、生产并发或长期会话的上线验收。

## Decisions so far

<!-- 每个已解决票据仅在此保留标题、链接与一句结论；完整答案放在该票据的解决评论。 -->

- [确定账号、房间与邀请关系](issues/01-decide-account-room-and-invitations.md#解决评论账号房间与邀请规则已确认)：开放注册与建房，采用统一可恢复账号；房间邀请须经房主审批，离开释放昵称并清除本人标签，首版不转让房主；具体账号细则由安全票后续确认。
- [确定公共与个人歌单权限及生命周期](issues/02-decide-playlist-permissions-and-lifecycle.md#解决评论歌单权限与生命周期规则已确认)：授权后选账号建房，歌单按需主动配置，房主可共用已有或只读收藏歌单；离开与删房清理专用云端歌单，已有歌单仅解除绑定。
- [确定文本导入与公共点歌语义](issues/03-decide-import-and-song-request-semantics.md#解决评论文本导入与公共点歌规则已确认)：采用百行、五候选与一次确认的简单导入；公共点歌可直接搜索或来自自己的可选个人歌单，个人来源须核对，成功须确认云端歌曲与本人标签。
- [验证授权复用、账号隔离与官方客户端共存](issues/04-verify-auth-reuse-and-client-coexistence.md#解决评论固定基线的小量实测通过)：固定 PC 基线与账号隔离原型通过小量复用及双向共存实测，收藏可由 API 列举，专用歌单清理已完成；生产与长期边界仍须复验。
- [确定多歌单并发、同步与失败恢复](issues/05-decide-concurrency-sync-and-recovery.md#解决评论并发同步与恢复规则已确认)：账号串行与按需共享快照，逐首写后同步、未知结果只补查，正常成功路径简化，授权恢复与专用清理隔离，首版逐调用进程隔离。
- [确定多房间安全、部署与运维边界](issues/06-decide-security-deployment-and-operations.md#解决评论安全部署与运维边界已确认)：采用 Better Auth 默认认证与 TypeScript/Node.js，自用单机及最小资源限制、服务器管理命令和日志，不做备份系统；可信 HTTPS 与资源留作部署前验收。

## Not yet specified

- 核心交互原型完成后，再判断已确定的成员资格与审批状态之外的辅助成员信息是否值得纳入首版，以及它们应如何呈现。

## Out of scope

- QQ 音乐、酷狗音乐等非网易云平台的授权与歌单接入，属于后续独立努力；当前地图只形成网易云 MVP 规格，不预先设计其他平台的适配架构。
- 自动播放、切歌、暂停、当前歌曲识别、播放进度、官方客户端播放队列同步、自带播放器和音频传输。
- 房主电脑上的本地助手、代理、脚本或内网穿透。
- 为室友个人歌单要求其提供网易云授权；为同一用户并行绑定多个网易云账号或配置房间级授权覆盖。
- 其他室友编辑别人的个人歌单，或从别人的个人歌单向公共歌单点歌；个人歌单自动汇总到公共歌单。
- 独立于网易云的歌曲集合与顺序、公共点歌主动置顶、已有歌曲因重复点歌被主动重排。
- 导入的智能匹配、跨设备草稿与导入历史：以简单稳定为首版边界，见[确定文本导入与公共点歌语义](issues/03-decide-import-and-song-request-semantics.md#解决评论文本导入与公共点歌规则已确认)。
- 原生移动或桌面应用、公开音乐社区运营、商业化、服务等级保证和规避网易云风控的承诺。
