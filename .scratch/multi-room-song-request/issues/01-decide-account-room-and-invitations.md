# 确定账号、房间与邀请关系

Type: grilling
Label: wayfinder:grilling, resolved
Status: resolved
Assignee: Codex

## Question

可恢复的点歌台账号如何注册、登录和找回身份，账号、房间成员和房主角色应如何关联，建房邀请码和房间邀请各授予什么资格？需确定一个账号创建或加入多个房间的边界、邀请码消费与撤销、房间切换、成员重新进入、房主身份恢复，以及昵称与账号信息各自的作用。

## Comments

- 用户确认每房间一份当前有效的邀请，邀请链接和邀请码对应同一加入资格，可多人重复使用，不自动过期。房主可重置邀请，使旧链接和旧码同时失效，不影响已加入成员；不设置单人邀请或次数限制。
- 界面显示邀请码和“复制邀请链接”按钮，不直接展示链接文本。用户目前无域名，以 IP:Port 访问；不因此取消链接入口。

- 用户确认首版不支持房主转让。创建者始终是该房间房主，不能像室友一样退出自己的房间；房间删除及歌单处理由生命周期票决定。

### 第二轮确认：开放准入与房间邀请

- 用户确认开放注册，登录后自由建房；不设置注册邀请码或建房邀请码。加入别人房间仍需有效房间邀请。
- 用户要求房间邀请同时提供链接和码两种入口；用户接受“邀请链接 / 邀请码”或“房间链接 / 房间码”的称呼，其具体凭据关系、有效期及撤销规则待确认。
- 用户确认持有有效邀请并登录即可直接加入，无逐人审批。
- 用户确认用户名全站唯一、首版不可修改；房间内显示可修改的房间昵称，不以用户名作为默认公开身份，不设置全站显示名。
- 密码恢复以用户最新输入为准：用户倾向取消恢复码，不提供自助忘记密码功能，由服务器管理员查询或重设密码。须明确原密码不能查询、仅可重设，并确认人工重设流程；第一轮同意独立恢复码的输入不再作为最终规则。

### 第一轮确认：账号入口与多房间角色

- 用户同意采用用户名 + 密码，并提供独立恢复码；点歌台登录与网易云授权分离。恢复码使用及丢失后的处理仍待确认。
- 用户同意一个账号可以创建或加入多个房间，角色按房间确定，每个房间只有一名房主；同一账号在不同房间可以使用不同昵称。数量上限留给安全与规模决策。
- 注册与建房准入尚未确定。用户提出：若注册必须受邀，注册后建房不应再需要邀请；或直接开放注册与建房，以自用及周围同学为主要使用者，不默认存在恶意注册和建房。建房邀请码是否存在及其语义等待此分支决定，不能采用先前的一码一次建房建议。

### 已确认输入：用户级网易云绑定与授权复用

用户已明确确认：每个点歌台用户同一时间绑定一个网易云账号，其创建的全部房间自动复用该授权；歌单与成员权限仍按房间隔离，不自动复用或合并歌单。成员在别人房间操作时使用该房间房主的授权，不使用操作者自己的授权。

授权失效或主动退出影响该用户创建的全部房间，不影响其作为室友加入的其他房间；同账号重新授权后共同恢复。更换网易云账号影响全部自建房间，各房间须重新设置歌单，不能直接沿用旧账号歌单绑定，也不自动删除云端旧歌单。

房主和室友都使用可恢复的点歌台账号，不再采用浏览器凭据丢失后创建新身份的匿名模型。建房邀请码用于建房资格、房间邀请用于加入资格的流程此前已提出，但注册是否需要邀请、建房码是否逐房间一次消费、账号与成员恢复机制仍需在本票据明确，不能把建议当成确认。

### 第五轮变更：审批加入、昵称释放与密码问题

- 用户以邀请泄露后大量陌生人加入的场景，要求改为房主审批加入。有效邀请仅允许申请，房主批准后才取得成员资格；此输入替代此前“持有效邀请直接加入、无逐人审批”的确认。
- 用户不采用“移除即房间封禁”。退出或被移除的账号希望重新加入时，也须由房主同意，不设置独立房间黑名单。
- 用户明确不保留离开成员的昵称：退出或被移除后释放昵称，并清除其歌曲的点歌人标签；新成员可以使用该昵称，但不继承原成员数据。标签清除范围及原账号重新加入后的个人歌单处置需精确界定，后者交由生命周期票。
- 邀请展示权限等待审批模型展开后确认，不能将此前“只有房主可见”的建议视为已决定。
- 用户质疑普通改密校验当前密码的意义。需区分忘记密码后的管理员重设与知道密码时主动修改；是否提供普通修改密码入口尚未确认，不沿用上一轮未获同意的账号设置建议。

### 第六轮确认：审批流程、邀请权限、标签清理与改密

用户对本轮全部问题均同意推荐方案，确认如下：

- 登录后通过有效邀请填写拟用昵称并提交加入申请，批准前不能查看歌单或操作房间。同一账号在同一房间只保留一份待处理申请，申请人可以撤回，房主可以批准或拒绝。
- 待处理申请的昵称不占用；批准时若昵称已被当前成员使用，申请人须修改昵称后再提交。
- 房主重置邀请，同时取消旧邀请产生的待处理申请；已加入成员不受影响。退出或被移除后再次加入，也须通过当前有效邀请走申请和审批流程，不直接恢复访问权限。
- 只有房主能在房间界面查看邀请码、复制邀请链接和重置邀请。室友仍可转发已经拿到的邀请，但不提供室友的邀请入口；审批由房主负责。
- 成员退出或被移除后，仅清除该成员本人的点歌人标签，保留其他成员的标签，不因此删除公共歌单歌曲。原账号重新获批加入不恢复已清除的旧标签；新人使用同一昵称也不继承旧标签或原成员数据。
- 保留主动修改密码入口，须校验当前密码；忘记密码则由服务器管理员重设，后者不要求用户提供旧密码。取消恢复码、邮箱找回及自助忘记密码流程的既定规则不变。
- 账号与房间关系的主要决策已收敛，等待完整汇总的共同理解确认后再记录解决评论及关闭票据。个人歌单与其他数据的离开后处置、具体安全实现及资源上限继续留给后续票据。

### 解决评论：账号、房间与邀请规则已确认

用户已明确确认完整汇总。本评论为本票最终决议，取代上述讨论中与之冲突的旧建议和阶段性确认。

#### 账号与密码

- 开放注册，以全站唯一、不可修改的用户名和密码登录；登录身份与网易云授权分离，不设置注册邀请码或建房邀请码。
- 登录用户名不作为房间内默认公开名称，不设置全站显示名。房主与室友均使用可恢复的点歌台账号，换浏览器登录原账号不会新建成员身份，但不能恢复已经结束的房间成员资格。
- 保留主动修改密码入口，须校验当前密码；忘记密码时线下联系服务器管理员，由其核实后为原账号重设临时密码并撤销已有登录会话，用户再次登录后必须修改密码。重设密码不改变账号、房间及成员身份，也不撤销房主主动结束的成员资格。
- 密码只保存不可逆哈希，不允许查询原密码。服务器管理员是部署维护者，不是房主；房主不能重设室友密码。
- 不设置恢复码、邮箱找回、自助忘记密码功能或站内管理员后台。具体密码策略、会话机制、管理员操作与核实流程由安全票决定。

#### 房间、角色与主页

- 登录后可自由建房，一个账号可创建或加入多个房间；角色、成员身份和昵称按房间区分，数量上限交由安全与规模决策。
- 每个房间只有一名房主，创建者始终是房主。首版不支持转让房主，房主不能像室友一样退出自己的房间；房间删除规则由生命周期票决定。
- 建房时填写房间名称与房主在该房间的昵称。房间名称可重名、不作为加入凭据，房主可修改房间名称。
- 主页只展示自己创建或当前加入的房间，点击进入，切换时返回主页再选择其他房间。不另设房间切换器，不做全站房间目录、房间搜索或按房间名申请加入。
- 每个用户同一时间绑定一个网易云账号，其全部自建房间复用该用户的服务端授权；成员操作使用目标房间房主的授权，而非操作者自己的授权。各房间歌单和成员权限独立，不复用或合并歌单。
- 网易云授权失效或主动退出影响该用户全部自建房间，不影响其作为室友加入的其他房间；同账号重新授权后共同恢复。更换网易云账号须为全部自建房间重新设置歌单，不自动删除旧云端歌单。

#### 房间邀请与加入审批

- 每个房间只有一份当前有效邀请。邀请链接与邀请码对应同一申请资格，可多人重复使用、不自动过期，不设置单人邀请或次数限制。
- 只有房主能在房间界面查看邀请码、复制邀请链接和重置邀请。界面不直接展示完整链接文本；当前使用 IP:Port 访问仍保留复制链接入口。室友可转发已取得的邀请，但界面不提供室友的邀请入口。
- 未登录的邀请访问者先登录或注册，再继续申请加入。登录后通过有效邀请填写拟用昵称并提交申请，由房主批准后才取得成员资格；批准前不能查看歌单或操作房间。
- 同一账号在同一房间只保留一份待处理申请；申请人可撤回，房主可批准或拒绝。申请中的昵称不占用，批准时若昵称已被当前成员使用，申请人须修改昵称后再提交。
- 房主重置邀请时，旧链接与旧码同时失效，并取消旧邀请产生的待处理申请；不影响已加入成员。当前成员再次进入房间不需要邀请。
- 邀请泄露不会直接增加成员，但仍可能带来陌生人的加入申请；申请频率及资源限制由安全票决定，不引入真人身份核验。

#### 成员离开、昵称与标签

- 室友可主动退出，房主可移除室友；资格结束后立即失去房间访问和操作权限。不设置房间黑名单，退出或被移除后的账号可通过当前有效邀请重新申请，须再次获得房主批准，不直接恢复访问。
- 室友首次申请填写拟用昵称，不默认公开登录用户名；成员仅可修改自己的昵称，房主不能替室友修改。当前成员在同一房间不能重名，同一账号在不同房间可使用不同昵称。
- 改名释放旧昵称，退出或被移除也释放昵称。新人可以使用原昵称，但同昵称不代表同一成员，不能继承原成员数据。
- 退出或被移除时，仅清除该成员本人的点歌人标签，保留其他成员标签，不因此删除公共歌单歌曲。原账号重新获批加入不恢复已清除的旧标签，新成员使用旧昵称也不继承旧标签。
- 原账号重新加入后的个人歌单、绑定与快照如何恢复，以及成员离开或房间删除时云端歌单如何保留或清理，均由生命周期票决定；本票不承诺离开后个人歌单一定保留。
