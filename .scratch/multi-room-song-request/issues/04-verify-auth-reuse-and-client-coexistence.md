# 验证授权复用、账号隔离与官方客户端共存

Type: prototype
Label: wayfinder:prototype
Status: open

## Question

在低风险真实账号原型中，同一份用户级网易云授权能否用于多个房间的独立歌单，并在同一服务内与其他房主账号正确隔离？首次授权、重新授权、官方电脑客户端重新登录对双方会话有何影响，能否满足点歌台与官方客户端同时可用的上线门槛？需核查依赖的 Cookie/设备参数隔离，记录版本、操作范围、观察结果与未证实条件；若失败，决定可验证的完整授权方式或确认方案被阻塞。

## Comments

### 证据入口与 HITL 边界

用户级复用前提见[确定账号、房间与邀请关系](01-decide-account-room-and-invitations.md#已确认输入用户级网易云绑定与授权复用)。既有 [扫码授权平台调查](../../dorm-song-request/issues/06-decide-public-room-and-auth-security.md#调查证据扫码授权平台与官方客户端会话影响) 仅证明默认参数，未实测官方客户端并存。

用户已确认同时可用为上线验收条件。本票据为 HITL：开始前与参与房主确认账号、专用测试歌单、操作及观察时机，由人扫描和确认；不自行获取凭据、不压测、不记录原始 Cookie，也不把未合入的 Web 登录修改视为已经可用。

测试不能只观察播放器继续出声或点歌台页面缓存；需验证真实登录请求、歌单读取及约定的低频写入。账号隔离不能仅依靠不同界面按钮，须验证调用实际使用的凭据与目标歌单。

### 歌单生命周期决议补充的验证门槛

以[确定公共与个人歌单权限及生命周期](02-decide-playlist-permissions-and-lifecycle.md#解决评论歌单权限与生命周期规则已确认)为约束，在用户明确批准的专用测试范围内补充验证：按需创建、读取和删除专用歌单；同一房主跨房间共用同一已有个人歌单；收藏来源读取并把所选歌曲写入可维护目标；无权限、授权失效和确认删除的结果判别。不能向原作者的收藏歌单发起写入，不能删除日常已有歌单，也不能将自建歌单的旧实测冒充全部收藏歌单或共享歌单权限证明。

建房选账号只复用当前用户已有的网易云授权，本票不扩展到多网易云账号绑定或其他音乐平台。来源类型、清理目标及多房主凭据都须实际核对，不以界面正确作为隔离通过的证据。

### 导入与点歌决议补充的验证入口

以[确定文本导入与公共点歌语义](03-decide-import-and-song-request-semantics.md#解决评论文本导入与公共点歌规则已确认)为产品约束，核对搜索单曲候选的实际字段与数量参数，明确歌名、歌手、专辑和歌曲 ID 的展示及校验依据，不假定首候选准确或依赖未文档化的置信度。补充重复歌曲、混合新旧歌曲批次与写后读回的证据，标明哪些异常仅可由可控测试模拟。

百行输入和五候选是产品取舍，不是上游批次上限或容量实测。超过原批准范围的真实账号调用须重新确认，不自行压测或制造账号风险；本票记录接口事实，失败调度与恢复仍由并发票据决定。
