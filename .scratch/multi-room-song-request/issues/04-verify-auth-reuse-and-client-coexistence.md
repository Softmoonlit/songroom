# 验证授权复用、账号隔离与官方客户端共存

Type: prototype
Label: wayfinder:prototype
Status: open

## Question

在低风险真实账号原型中，同一份用户级网易云授权能否用于多个房间的独立歌单，并在同一服务内与其他房主账号正确隔离？首次授权、重新授权、官方电脑客户端重新登录对双方会话有何影响，能否满足点歌台与官方客户端同时可用的上线门槛？需核查依赖的 Cookie/设备参数隔离，记录版本、操作范围、观察结果与未证实条件；若失败，决定可验证的完整授权方式或确认方案被阻塞。

## Comments

### 证据入口与 HITL 边界

用户级复用前提见[确定账号、房间与邀请关系](01-decide-account-room-and-invitations.md#已确认输入用户级网易云绑定与授权复用)。既有 [扫码授权平台调查](../../dorm-song-request/issues/06-decide-public-room-and-auth-security.md#调查证据扫码授权平台与官方客户端会话影响) 仅证明默认参数，未实测官方客户端并存。

用户已确认同时可用为上线验收条件。本票据为 HITL：开始前与参与房主确认账号、专用测试歌单、操作及观察时机，由人扫描和确认；不自行获取凭据、不压测、不记录原始 Cookie，也不把未合入的 Web 登录修改视为已经可用。

测试不能只观察播放器继续出声或点歌台页面缓存；需验证真实登录请求、歌单读取及约定的低频写入。账号隔离不能仅依靠不同界面按钮，须验证调用实际使用的凭据与目标歌单。
