# 确定公共与个人歌单权限及生命周期

Type: grilling
Label: wayfinder:grilling
Status: open
Blocked by: 01

## Question

每个房间的公共歌单和成员个人歌单如何创建或绑定，成员加入、退出、被移除、房间删除、歌单失去访问权限及房主更换网易云账号时，云端歌单、绑定、快照与标签分别如何处理？需确定房主在点歌台是否与普通成员采用相同歌单权限，公共删除/清空/排序及个人歌单维护提供哪些操作，并明确跨房间不得共用绑定歌单的边界。

## Comments

### 已确认输入与待确认权限

用户确认公共与个人歌单共存，每房间一份公共歌单，每个成员包括房主各有一份个人歌单，均位于房主网易云账号下。个人歌单对房间成员可见，其他室友只读，不能从别人的个人歌单向公共歌单点歌；只能从自己的个人歌单逐首操作，不自动汇总到公共歌单。

用户提出房主主要使用网易云官方客户端，点歌台内歌单权限应考虑与其他成员相同。此前“房主可管理别人个人歌单”和之后“不提供房主额外编辑权限”的建议不能同时当作最终规则；本票据须明确这一分歧。公共和个人歌单均是网易云快照，不保留额外的本地歌曲集合或独立顺序。

用户级授权及更换账号影响全部自建房间的输入见[确定账号、房间与邀请关系](01-decide-account-room-and-invitations.md#已确认输入用户级网易云绑定与授权复用)。相关数据清理、恢复和不可逆操作须在本票据决定。
