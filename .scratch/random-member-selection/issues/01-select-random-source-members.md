# 01：随机点歌按所选成员生成预览

**What to build:** 房主打开随机点歌弹窗后，以 checkbox 选择参与成员及总首数，手动生成并确认歌曲预览。前后端共同保证只有所选成员的个人歌单参与抽选、贡献和来源校验。

**Blocked by:** 无，产品规则已确认。

Status: ready-for-agent

规格：[随机点歌选择成员](../spec.md)。

## 验收清单

- [ ] 每次打开弹窗成员默认全不选，未选择时禁用生成并显示提示；总首数沿用 5/10/15/20 首，默认 10 首。
- [ ] 当前房主及室友按房间昵称展示；未创建个人歌单的成员禁用并注明原因，已有歌单即允许选择，实际空歌单贡献 0 首。
- [ ] 全选 checkbox 只操作可选成员，完整支持未选、半选和全选；半选点击变全选，全选点击取消全部。
- [ ] 打开、勾选或切换首数不自动生成预览；点击生成后才读取来源；预览可返回调整，调整后不能确认旧预览；重新抽选保留本次成员及首数。
- [ ] 预览命令要求明确的非空成员集合；服务端验证当前房间成员身份及个人歌单配置，拒绝越房间成员、已离开成员、未配置成员及未提供选择的旧请求，不添加默认全体成员的兼容分支。
- [ ] 仅刷新所选成员个人来源，未选来源故障不影响本次；所选来源读取失败或失效则整次预览失败，不能跳过或使用旧快照。
- [ ] 所选来源全部为空时显示明确提示，不能确认替换或清空公共歌单；候选不足时按现有规则展示实际首数，不能从未选成员补歌。
- [ ] 在所选成员内保持公平分配、歌曲 ID 去重、交叉候选归属、名额重分配及整组洗牌；不引入新旧歌优先级。
- [ ] 预览固定所选来源及逐曲归属，确认和执行复用现有校验；所选成员离开、绑定或来源失效会拒绝，未选成员的变化不影响本次来源校验。
- [ ] 所有来源的读取、确认与执行仍受房主权限、授权、公共目标、预览有效期和冲突协调限制；保持持久操作、批量替换、未知写确认和标签生命周期规则。
- [ ] 覆盖契约及服务端测试：缺失/空选择、非法成员、单人及多人来源、只读取选中来源、空来源、读取失败、选中/未选成员变化、预览确认与标签归属。
- [ ] 覆盖浏览器测试：默认无选择、禁用项、全选/半选/取消全选、手动生成、返回修改、重新抽选、关闭重开、空及失败反馈、房主与室友权限；检查移动端布局与 checkbox 键盘操作。
- [ ] 完成类型检查、受影响回归及规范/规格审查；交付前更新本票状态、清单与评论，记录实现提交、实际验证结果和剩余事项。

## Comments

- 需求访谈：用户逐项确认 checkbox 多选、默认不选、先选择再生成预览、未建歌单成员禁用、空来源贡献 0 首、半选点击全选以及来源读取失败边界，详见规格讨论记录。
- 代码探索：现有预览请求只有 `count`，弹窗打开即生成预览，服务端读取所有已配置个人来源；本票须贯通界面、契约与服务端来源范围，不能只添加前端筛选。
