# 05: 成员退出/删房生命周期与多账号端到端全链路验收

**What to build:** 验证无害化生命周期与端到端稳定性：成员退出或被移出房间时级联删除该成员在房间内的个人歌单绑定与公共歌单标签，该成员用户级网易云授权保留，云端歌单零写调用；房主删除房间时清理公共专用歌单，全员个人歌单仅本地解除绑定，绝不删除云端歌单或取消收藏；成员在账号设置更换网易云账号时各房间旧绑定自动失效；运行全量单元测试、HTTP 集成测试与端到端浏览器测试，完成全功能回归闭环。

**Blocked by:** 02: 房间成员列表布局重排与他人歌单隐私收敛, 04: 随机点歌多成员独立账号抽选与异常置灰

**Status:** ready-for-agent

## Acceptance criteria

- [ ] 成员主动退出房间或被房主移出房间：级联删除该成员在当前房间的 `personal_playlist_binding` 行及对应的点歌人标签；成员在点歌台用户级的网易云授权保留，云端个人歌单零网络写调用
- [ ] 房主删除房间：清理点歌台公共专用网易云歌单，房间内所有成员（房主与室友）的个人歌单仅在本地数据库解除绑定，绝不删除任何人的云端歌单或取消收藏
- [ ] 成员在全局账号设置中主动更换网易云账号：该成员在所加入房间的个人歌单绑定自动失效，进入房间恢复为“未绑定歌单”状态
- [ ] 废弃接口与废弃数据表逻辑完全清理，无残留死代码或兼容垫片
- [ ] 运行全量单元测试与 HTTP 集成测试全部通过，无回归失败
- [ ] 端到端回归验证：多成员登录、各自绑定网易云账号、进入同一房间自选绑定不同歌单、逐首点歌与随机点歌完整闭环跑通
