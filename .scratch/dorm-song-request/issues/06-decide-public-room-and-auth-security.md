# 确定公网房间与网易云授权安全边界

Type: grilling
Status: resolved
Assignee: Codex

## Question

在公网 VPS 上，房主扫码授权、房主身份、室友邀请链接、临时成员会话、邀请重置、网易云 Cookie 存储和重新授权应采用什么安全模型，才能让室友只获得规定的房间权限，且网易云凭据永不暴露到室友浏览器、URL、前端日志或公共接口？

答案还必须明确丢失邀请链接、昵称冒用、跨站请求、接口滥用、服务端日志和数据库泄露时的边界与恢复动作。

## Comments

### 第一轮反馈：部分边界已确认

用户已确认以下边界，票据保持开放。

- 区分“更换邀请链接”和“撤销全部室友访问”：前者只阻止旧链接继续加入，不影响已加入室友；后者同时更换邀请链接并撤销全部室友凭据，房主不受影响。按既有身份规则，凭据失效后重新加入属于新成员，不接管旧昵称或旧标签。用户提出还应讨论单独踢出某个室友的操作，其效果与防止重新加入的边界尚待确认。
- 首版信任邀请链接持有人，不增加逐人审批或实名核验；昵称只是显示名称，不能证明真人身份，接受尚未使用的昵称可能被抢占。房主标识来自权限而非昵称，室友不能通过改名获得房主标识或权限。
- 仅数据库或备份泄露时，网易云 Cookie 应受加密保护，解密密钥不得放在数据库或同一备份中；房主密码、本地会话和邀请令牌不以可直接使用的明文存储。普通业务数据不承诺保密。
- VPS 或应用运行环境被攻破时，视为网易云授权和本地访问凭据全部可能泄露；停止服务、撤销相关凭据，修复后重新授权。不承诺抵御已经控制服务器的攻击者。
- 日志不得记录密码、Cookie、邀请令牌、会话令牌或扫码授权原始响应。具体密钥保存和备份部署方式留给“确定部署运维与故障恢复方案”。

房主身份方案尚未确认：用户要求先澄清房间初始化、房主登录、网易云授权与歌单绑定的关系，以及房主和室友再次进入时使用的凭据。

### 第二轮确认：唯一房间初始化与单独踢出

用户已确认以下决定，房主身份与单独踢出的问题据此收敛；有效期、重新授权与接口防护仍待讨论。

- 部署时确定唯一房间与独立的点歌台房主密码，不提供公开注册或创建房间入口。房主先登录点歌台，再扫码授权网易云账号，选择或创建专用点歌歌单，最后分享邀请。创建歌单不等于创建房间。
- 一个房间绑定一份点歌歌单，由一个房主网易云账号提供授权。网易云扫码不授予点歌台房主身份；歌单绑定不代表可以任意操作该账号下的其他歌单。
- 房主与室友均由浏览器保存访问凭据，服务端校验身份和权限。房主凭据丢失或失效后，通过房主密码重新登录，仍是原房主；室友凭据丢失或失效后，通过当前邀请重新加入，属于新成员。室友不设置账号密码，昵称不能认领身份。
- 服务端网易云授权有效时，房主再次登录点歌台不要求重新扫码；授权失效时才要求房主重新授权。
- 提供单独踢出室友的操作：撤销指定室友全部访问凭据，保留该成员记录、昵称与现存标签，其他成员不受影响。踢出不自动更换邀请链接；更换邀请由房主通过专门操作执行。
- 接受匿名邀请的限制：被踢出的室友仍可使用有效邀请，以新成员身份重新加入；不保证永久禁止某个真人返回，也不允许新成员接管旧昵称或标签。

### 第三轮反馈：凭据有效期、邀请有效期与账号纠错

用户已确认凭据和邀请规则，并要求修正原先建议的账号不可更换限制。

- 房主登录凭据在登录后 7 天到期，到期需重新输入房主密码，仍是原房主；服务重启不主动使其失效。
- 室友凭据连续 180 天未使用后到期，正常使用延长有效期；被踢出或撤销全部室友访问时立即失效。失效后原昵称与标签保留，重新加入属于新成员，须选择其他可用昵称。
- 房主和室友凭据采用持久化安全 Cookie，前端脚本不能读取，不存入 localStorage。房主可通过密码在不同浏览器登录同一房主身份；室友不支持跨浏览器身份认领。
- 邀请链接不自动过期，直到房主主动更换或撤销全部室友访问；邀请只用于加入，不作为已加入成员的身份凭据。
- 服务端仅保存邀请令牌的校验摘要，新邀请在生成时交给房主分享。房主丢失原邀请后，通过生成新邀请恢复分享，旧邀请失效，已加入室友不受影响；不提供从数据库找回原邀请令牌的功能。
- 用户指出首次绑定可能扫错账号，因此必须提供更换网易云账号和退出网易云授权的功能，不采用“首次绑定后禁止更换账号”的建议。退出与更换时如何处理原歌单绑定、成员、标签及待执行操作，仍待确认。

### 第四轮确认：退出授权与更换账号的数据边界

用户对本轮两项建议全部表示同意。

- 扫码成功后先向房主显示账号信息，确认后完成绑定；确认前可以放弃本次授权并重新扫码，确认后仍可通过更换账号纠错。同一时间只使用一个网易云账号，不提供多个账号并行管理。
- 退出网易云授权时删除点歌台服务端保存的网易云 Cookie，停止使用该授权访问网易云；保留原账号标识、歌单绑定、成员、昵称、标签及最后同步的歌单快照。禁止所有歌单写操作，可以查看标记为未授权、非实时的最后快照。
- 退出只作用于点歌台保存的网易云授权，不代表使手机或电脑上的官方客户端退出，也不承诺撤销网易云侧所有登录会话。之后重新授权同一账号时继续使用原歌单，按实际云端状态同步。
- 更换账号期间暂停歌单写入；房主确认新账号及其专用点歌歌单后替换授权与绑定，删除旧授权并清除原歌单全部点歌人标签。新歌单已有歌曲无标签；不删除或清空云端旧歌单，也不自动复制旧歌曲。
- 更换账号不改变点歌台房主身份，保留原房间、室友身份、昵称、邀请与有效访问凭据。重新授权同一账号且绑定同一歌单时不主动清除标签，按实际歌曲增删同步。
- 扫错、取消或绑定失败不提交新绑定，不提前清除旧标签；已主动退出的旧授权不会因此恢复。切换时在途操作和旧结果的隔离机制由“确定并发点歌与失败一致性规则”决定，必须防止旧操作或旧授权结果作用于新绑定。

接口权限、跨站请求防护、滥用处理与房主密码恢复规则仍待最终确认。

### 第五轮反馈：接口防护、滥用处理与房主恢复

用户基本同意接口防护，要求澄清“加入入口”；同意限流和房主恢复方案，并提出扫码授权的平台及官方客户端登录影响需要事实调查。

- “加入入口”指有效邀请链接打开后的昵称填写与加入页面，不是公开房间列表、公开注册或无邀请加入通道。没有有效房间凭据的人必须持有有效邀请才可加入；仅访问站点不能获得房间权限。
- 未认证的访问不能查看房间歌单、标签、成员信息或使用搜索。室友只能查看房间、搜索、点歌和修改自己的昵称；成员、邀请、网易云授权及歌单删除、清空、排序管理仅限房主。
- 服务端每次校验身份、权限和当前歌单绑定，不依赖隐藏按钮，不接受请求参数指定任意其他歌单。Enhanced 不直接暴露公网，不提供任意网易云接口代理；浏览器只得到筛选后的业务数据，房主浏览器也不得获得网易云 Cookie。
- 全站 HTTPS，身份 Cookie 禁止脚本读取并限制跨站携带；状态变更请求校验来源并实施 CSRF 防护，不通过 GET 执行。昵称等输入作为普通文本显示；邀请令牌不进入访问日志或第三方资源请求，授权相关响应禁止缓存。
- 超出限额时明确拒绝并提示稍后再试，不无限排队或持续重试。登录和加入按来源限流，搜索与写操作再按成员和房间总量限制，限制请求大小、批量数量和待处理数量，不通过改名或创建多个成员绕过房间总量限制。
- 首版不增加验证码、实名核验或复杂反作弊系统。具体限额与冷却时间由“确定部署运维与故障恢复方案”决定，串行化、重试和失败处理由“确定并发点歌与失败一致性规则”决定。
- 不设置公开的忘记密码找回入口。通过 VPS 运维入口重置房主密码，同时撤销全部旧房主会话和未完成扫码流程；仍是原房主，房间、室友、邀请、绑定与标签不变。
- 仅重置点歌台密码不自动退出网易云授权，也不保护已经泄露的网易云 Cookie。怀疑网易云凭据泄露时，需另外处理网易云侧授权撤销和重新授权。

### 调查证据：扫码授权平台与官方客户端会话影响

- [`option.js`](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/a8c781fd64faab17fedfd46e0615a2609307f163/util/option.js#L1-L18) 未传 crypto 时产生空字符串；[`request.js`](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/a8c781fd64faab17fedfd46e0615a2609307f163/util/request.js#L211-L214) 按配置选择 eapi 或 api，基线配置开启加密，因此默认使用 eapi。
- [`request.js`](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/blob/a8c781fd64faab17fedfd46e0615a2609307f163/util/request.js#L141-L157) 以 `osMap[cookie.os] || osMap['pc']` 选择设备参数，并以 `cookie.os || os.os` 写入 os；没有覆盖参数时使用 `os: 'pc'`。二维码 platform 与请求层 os 是不同参数，不能把只改 platform 等同于完整切换 Web 登录链路。
- 既有原型分支 `prototype/verify-playlist-write-semantics` 的 `prototypes/verify-playlist-write-semantics/login.js` 调用 `login_qr_key()`、`login_qr_create({ key, qrimg: true })` 和 `login_qr_check({ key })`，未显式传 platform 或 crypto。实验验证了歌单写入，未记录电脑官方客户端是否保持登录。
- 扫码获得的 Cookie 由点歌台服务器保存和使用，不是在房主浏览器里登录网易云网页，也不是运行官方桌面客户端；但服务端调用不代表不受网易云多设备登录与风控策略约束。
- 不能仅凭 PC 参数、请求加密格式或 Cookie 名称推断官方电脑客户端必然被挤下线或绝不会被挤下线。当前没有可依赖的证据保证并存；须在真实使用场景中另行低风险验证。
- 调查时上游 [Fix login](https://github.com/NeteaseCloudMusicApiEnhanced/api-enhanced/pull/201) 仍开放、未合入，涉及 Web 模式及请求方式调整；不能将其作为基线已支持、已验证的替代登录方案。

尚待用户确认是否将“扫码授权后点歌台与官方电脑客户端能够同时保持可用”列为上线验收条件；若列入，需由后续实测票据承接，失败时不得直接宣称换成 Web 参数即可解决。本票据仍开放，未把不可验证的多端策略当作既定保证。

### 解决评论：最终安全规则已确认

用户已确认各轮安全决定，并确认客户端并存为上线验收条件。本票据已解决。前述评论保留为讨论过程，以下是最终规则；扫码平台证据见本票据“调查证据：扫码授权平台与官方客户端会话影响”。

1. **唯一房间与独立房主身份**：部署时确定唯一房间和点歌台房主密码，不开放注册或创建房间。先登录房主，再扫码、确认网易云账号并选择或创建专用点歌歌单，最后分享邀请。网易云授权不授予房主身份；同一时间只使用一个网易云账号和一份绑定歌单，允许主动退出或更换账号。
2. **浏览器凭据与有效期**：凭据不可猜测、由服务端校验和撤销，使用持久化安全 Cookie，不存入 localStorage，不让前端脚本读取。房主凭据登录后 7 天到期，室友凭据连续 180 天未使用后到期、正常使用续期。重启不主动使凭据失效，踢出或撤销立即生效。房主可用密码在不同浏览器恢复同一身份；室友凭据丢失或失效后默认新成员，不支持跨浏览器合并或同名认领。
3. **邀请与加入**：邀请不可猜测、不自动过期，仅用于加入，不充当已有成员凭据。服务端只保存令牌校验摘要，生成时交给房主分享；丢失后生成新邀请，旧邀请失效。加入入口仅是有效邀请打开后的昵称填写页面，不设公开房间列表、公开注册或无邀请加入路径。已有成员凭有效成员凭据再次进入，无须再次使用邀请。
4. **三个独立撤销动作**：更换邀请仅阻止旧链接继续加入，不影响已有成员；踢出指定室友仅撤销该成员全部访问凭据，不自动更换邀请；撤销全部室友访问同时更换邀请和撤销全部室友凭据，房主不受影响。三者均不转移或主动清除原成员昵称、身份记录和标签。被踢者仍可能持有效邀请以新成员重新加入，不承诺永久禁止某个真人返回。
5. **昵称信任边界**：邀请持有人可选择尚未使用的昵称，不增加审批、实名核验或真人身份认领。昵称不能证明身份；唯一性及标签归属沿用既定成员规则，原昵称不因离开、到期或被踢自动释放。房主标识和权限来自服务端身份，不能通过改昵称获得。
6. **最小接口权限**：未认证者不能查看歌单、标签、成员数据或搜索。室友只可查看房间、搜索、点歌和修改自身昵称；成员管理、邀请、网易云授权及歌单删除、清空、排序仅限房主。服务端每次校验身份、权限与绑定，不接受任意其他歌单参数。Enhanced 不公开暴露，不提供通用网易云接口代理。
7. **扫码与凭据隔离**：扫码和授权管理仅限已登录房主，扫码流程与发起它的房主会话绑定。返回浏览器的只有完成流程所需的二维码、状态和筛选后的账号信息，不传递原始授权响应或网易云 Cookie，房主浏览器也无例外。Cookie 加密存储，解密密钥不放在数据库或同一备份；房主密码安全散列，身份和邀请令牌只存不可直接使用的校验材料。
8. **跨站与前端防护**：全站 HTTPS，身份 Cookie 禁止脚本读取并限制跨站携带；状态变更校验来源和 CSRF 防护，不使用 GET 执行。昵称等按普通文本显示；授权响应禁止缓存，邀请令牌不进入访问日志或第三方资源请求。不将密码、Cookie、邀请令牌、身份令牌或扫码原始响应写入任何服务端或前端日志。
9. **授权失效与主动退出**：授权有效时不因再次登录房主要求重新扫码；授权失效时停止写入并要求房主重新授权。主动退出删除本地网易云 Cookie，停止使用该授权访问网易云，保留绑定、成员、昵称、标签及最后快照，仅以未授权、非实时状态展示。退出本地授权不代表官方客户端退出或上游所有会话撤销；同账号重新授权后按云端实际状态同步。
10. **更换账号与歌单**：扫描后先显示账号供房主确认，扫错可放弃重扫。更换期间暂停写入，确认新账号和新歌单后替换授权及绑定、删除旧授权并清除旧歌单标签；保留房间、成员、昵称、邀请和有效访问凭据。新歌单已有歌曲无标签，不删除云端旧歌单、不自动复制歌曲。取消或失败不提交新绑定、不提前清除旧标签；已主动退出的授权不自动恢复。同账号、同歌单重新绑定按实际增删同步，不主动清标签。
11. **滥用与过载处理**：登录、加入按来源限流，搜索和写操作再按成员及房间总量限制，限制请求大小、批量数量与待处理数量；改名或新增成员不能绕过房间总量。超额明确拒绝并提示稍后再试，不无限排队，不在上游限流后盲目持续重试。首版不引入验证码、实名核验或复杂反作弊系统。
12. **房主密码恢复**：没有公开忘记密码找回入口，由 VPS 运维入口重置密码，同时撤销全部旧房主会话与未完成扫码流程。仍为原房主，房间、室友、邀请、绑定、标签不变；不自动退出网易云授权。若 Cookie 也泄露，须另外处理网易云侧撤销与重新授权，不能认为重置点歌台密码已经解决。
13. **泄露边界**：仅数据库或备份泄露时，网易云凭据受加密保护、密码与本地令牌不可直接使用，但普通业务数据不承诺保密。VPS 或应用运行环境被控制时，视为网易云授权和本地访问凭据全部可能泄露，停止服务、撤销相关凭据、修复后重新授权，不承诺抵御已控制服务器的攻击者。
14. **官方客户端并存门槛**：用户已确认扫码授权后点歌台与官方电脑客户端必须能同时保持可用，覆盖首次授权、重新授权及官方客户端重新登录的双向影响。不通过则阻止上线并调查其他授权方式，不承诺永久不会被风控下线，也不把只改二维码 platform 当作已验证解决方案。当前基线默认 PC 模式，是否挤下线仍未实测。
