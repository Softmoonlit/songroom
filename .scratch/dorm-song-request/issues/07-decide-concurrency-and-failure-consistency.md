# 确定并发点歌与失败一致性规则

Type: grilling
Status: open
Blocked by: 03, 04, 05

## Question

当多名室友同时点歌、房主同时管理歌单，或网易云的“添加歌曲”和“提交顺序”只有部分成功时，系统应采用什么串行化、幂等、重试、写后校验与用户反馈规则，才能避免丢歌、重复标签、错误顺序和点歌台元数据与云端歌单永久分叉？

答案必须定义同一歌曲被多人同时点歌、不同歌曲同时置顶、请求超时但上游实际成功、登录中途失效和回滚不可用时的可观察结果。
