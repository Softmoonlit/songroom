# 宿舍点歌台决策地图

Label: wayfinder:map

## Destination

形成一份可直接进入开发的 MVP 产品与技术规格：房主在公网点歌台授权网易云账号并绑定专用点歌歌单，受邀室友通过昵称协作点歌，系统可靠维护云端歌单顺序与点歌人标签。

规格必须明确用户流程、权限、数据模型、第三方接口边界、并发与失败语义、安全边界、部署方式、交互方案和验收标准。

## Notes

- 领域采用根目录 [`CONTEXT.md`](../../CONTEXT.md) 中的术语；每次处理票据时先读取该文件，并按票据类型使用 `grilling`、`prototype` 或 `domain-modeling`。
- 首版只服务一个宿舍、一个房主、一个房间和一个点歌歌单，通过公网 VPS/云服务器提供服务。
- 房主使用自己的日常网易云主账号，并明确接受非官方接口可能造成的风控、失效或账号处罚风险。
- 房主扫码授权后选择或创建专用点歌歌单；Cookie 只保存在服务端，不进入浏览器、URL 或日志。授权失效时停止写操作并要求房主重新扫码。
- 室友通过不可猜测且可重置的邀请链接加入，以临时昵称参与，不注册账号。
- 室友和房主都可以点歌：新歌加入点歌歌单第一位，已有歌曲移到第一位；同一成员不会形成重复标签，多名成员可以共同成为同一首歌的点歌人。
- 室友不能删除、清空或任意排序；房主可以删除、清空和任意排序。不记录歌曲归属，不提供撤销。
- 点歌人标签保存在点歌台自己的数据库中，网易云歌单只保存歌曲和顺序。
- 点歌台不读取或控制播放队列。房主自行使用网易云官方客户端播放并处理刷新或重新播放。
- 账号与接口风险已由房主接受，但规格仍须使用最小权限、写入限流、串行化和错误校验降低非必要风险。

## Decisions so far

- [确认网易云接口能力与账号风险](issues/01-confirm-netease-api-capabilities-and-account-risk.md)：Enhanced 覆盖登录、搜索及云端歌单增删排序，但属于无稳定合同的非官方接口，房主选择接受主账号风险。
- [确认能否远程控制官方客户端播放队列](issues/02-confirm-remote-official-client-queue-control.md)：没有可从服务端可靠控制指定桌面客户端当前队列的 API，因此播放控制不进入产品边界。
- [验证点歌歌单写入语义](issues/03-verify-playlist-write-semantics.md)：真实账号实测确认完整序列写入与回读校验可可靠维护 200 首点歌歌单，但子集排序、重复添加和动态限流要求串行化及按最终云端状态判定成功。

## Not yet specified

- 核心交互完成原型后，再判断是否需要操作历史、最近点歌或成员状态等辅助界面；这些能力目前不足以形成独立、精确的问题。
- 部署与一致性方案确定后，再明确上线检查、监控和恢复手册的具体深度。

## Out of scope

- 自动播放、暂停、切歌、当前歌曲识别、播放进度以及官方客户端播放队列同步。
- 在房主电脑安装或运行桌面助手、本地代理、脚本、内网穿透服务或其他附加程序。
- 网易云“一起听”、跨端续播、点歌台自带播放器和音频传输。
- 多宿舍、多房间、多房主、多网易云账号或公开社区运营。
- 室友注册账号、原生移动端或桌面端应用。
- 商业化、服务等级保证，以及承诺规避网易云风控或账号处罚。
