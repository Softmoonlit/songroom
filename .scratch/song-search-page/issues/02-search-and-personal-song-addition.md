# 02：解耦全网搜索并实现个人逐首添加

Status: ready-for-agent

## 目标

依据[规格](../spec.md)，允许成员独立搜索，并将候选歌曲加入自己的可写专用个人歌单。

## 依赖

- [01：统一成员专用个人歌单与生命周期](01-unify-dedicated-personal-playlists.md)。

## 验收清单

- [ ] 全网搜索只要求有效成员与房主有效授权，不要求已存在公共歌单或个人歌单；保留短命搜索、分页、权限重验及统一账号调度。
- [ ] 新增本人个人歌单逐首添加业务命令与操作查询，服务端取得当前归属、绑定、目标与账号，不接受浏览器替换其他成员或任意目标。
- [ ] 受理、执行和确认校验成员、授权、绑定代次、目标可写、冲突、幂等及成员同房间单未完成写操作限制。
- [ ] 同歌曲 ID 已存在则不重复写入、不改变顺序；新歌逐首写入且完整读回，个人添加不修改公共歌单或点歌人标签。
- [ ] 支持排队、处理中、结果待确认、明确失败与完成，未知写入只确认不重发；切页/关页不取消，重启可按既有机制恢复。
- [ ] 撤权、绑定失效与晚到结果不会污染新绑定，成员和房间已删除时不恢复业务数据。
- [ ] 有意义的 HTTP/持久操作测试覆盖无公共配置、无个人配置仍可搜索、本人添加、去重、越权、读回未知、幂等与撤权竞态。

## 关联旧工单

承接旧 MVP 26 的搜索与单首添加要求，本票不扩展到单首删除、批量删除或文本导入。

- 规划：用户确认搜索只添加个人歌单且直接提交，成功留在搜索页。
- 当前仅建立工单，无实现提交、测试或部署结果。
