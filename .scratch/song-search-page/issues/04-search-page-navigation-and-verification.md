# 04：接入首个搜索标签页并完成交互验收

Status: ready-for-agent

## 目标

依据[规格](../spec.md)，完成搜索、个人存歌、个人来源点歌的页面流程，并验证五个一级标签页的交互。

- [02：解耦全网搜索并实现个人逐首添加](02-search-and-personal-song-addition.md)。

## 验收清单

- [ ] 导航依次为搜索歌曲、公共歌单、我的歌单、房间成员、房间设置；每次进入房间默认搜索歌曲，不记忆上次标签。
- [ ] 搜索页支持关键词、候选与加载更多；逐首添加只写个人歌单，不弹确认或目标选择窗。
- [ ] 未配置个人歌单仍能搜索，添加禁用且说明原因，提供前往我的歌单配置入口，不自动创建。
- [ ] 房主与室友我的歌单均展示主动创建专用歌单流程，移除已有/收藏候选绑定、更换与解绑旧入口。
- [ ] 添加成功留在搜索页并轻提示，已存在提示已在个人歌单；排队、待确认、失败与成功真实区分，不提前报成功。
- [ ] 同房间切换全部一级标签页后保留搜索关键词、结果和浏览位置；刷新或离开房间清空，不持久化搜索现场。
- [ ] 我的歌单可逐首点歌到公共歌单，准确反馈来源、云端与点歌人标签状态；他人歌单不展示该操作。
- [ ] 移除公共歌单全网点歌按钮与原抽屉，保留公共歌单内筛选、同步、播放指示及房主随机换歌。
- [ ] 更新旧默认页和旧抽屉相关测试，不保留废弃实现；运行类型检查及与本次变更相关的集成、恢复和浏览器测试。
- [ ] 浏览器覆盖房主/室友、无歌单状态、连续添加、个人点歌、切页保留及离房清空，并验证移动端五标签可访问、无横向内容溢出与基本键盘操作。
- [ ] 交付前更新本功能规格和全部工单的验收、状态及 Comments，记录实际提交、验证和剩余事项；未做真实网易云验收或部署不得宣称完成。
