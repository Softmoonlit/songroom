# 01：统一成员专用个人歌单与生命周期

Status: resolved

## 目标

依据[规格](../spec.md)，让房主与室友均主动创建本房间专用个人歌单，并完整承担专用云端资源的生命周期清理责任。

## 验收清单

- [x] 房主与室友统一专用创建，只能创建自己的个人歌单；同成员同房间最多一份，跨房间、成员和公共目标不得共用。
- [x] 沿用房主当前授权、既有命名、持久创建、幂等、未知结果核查和恢复，移除房主不可创建限制与已有/收藏绑定命令及界面。
- [x] 数据模型表达统一成员专用来源和必要创建证据，不保留按房主/室友区分旧来源的兼容分支。
- [x] 旧房主已有或收藏关联退出使用，保留原云端歌单和收藏，不搬歌；给出可审查的一次性退役与在途操作处置，不改实际部署数据或加入兼容垫片。
- [x] 成员退出/移除、房间删除的本地事务清除成员业务数据、绑定及不再引用的个人快照，并建立全部应清理专用云端资源的最小任务；删房包含房主个人歌单。
- [x] 清理责任关联原房主账号，不能误用发起创建的室友点歌台账号；房主重新授权可唤醒对应原账号清理。
- [x] 处理已获 ID 未绑定、未知创建、晚到响应、重启及删房竞态；不按名称猜测、不自动重发未知写入、不恢复已删除业务数据。
- [x] 删除确认与页面反馈更新为全部成员专用个人歌单，不影响其他房间和原有外部歌单。
- [x] 自动化验证权限、跨房间隔离、旧关联保护、正常清理、删除失败、恢复账号归属、创建与撤权竞态。
