# 房间体验修订：全站降噪、整页滚动、下一首播放与搜索扩展

Status: ready-for-agent

## 目标

落实用户的反馈：消除多层大标题与重复说明，统一桌面和手机的歌单滚动，修复网易云外部改名不同步，允许成员将公共歌曲安排到播放指示歌曲的下一首，通过动态图标与定位按钮展示播放指示，并增加直接搜索可浏览的歌曲数量。

本规格汇总[需求讨论及接口证据](issues/01-clarify-noise-scroll-order-and-playback.md)，用户已确认全部规则。用户最新修订取消拖动、任意位置排序和“移动到…”入口，采用每首歌曲后的“下一首播放”；此动作允许有限的公共云端顺序调整，取代旧 MVP 的完全禁止排序条款。其他房间权限、个人歌单权限与生命周期规则继续适用。实现与验收记录见[实现票](issues/02-implement-room-experience.md)。

## 全站降噪

- 审视首页、登录/注册、房间列表、建房、邀请/申请、账号设置、房间工作台及其弹窗和抽屉，清理重复标题、身份镜像、常识说明和正常状态的长期占位。
- 每页保留一个主要视觉标题，必要的分区标题保持从属；不以统一缩小字号代替信息层级整理。
- 房间名显示为紧凑的“房间 · 343”上下文，不再把纯数字房间名当作突出的独立大标题。
- 公共歌单页主标题固定为“公共歌单”，不再同时突出显示云端歌单名称。歌单名称等详情放到房间设置的歌单详情中，以普通信息呈现。
- 移除点歌按钮旁的信息按钮及其原浮层，不另加同义图标入口。
- 点歌人列保留“点歌人”表头，各歌曲标签只显示昵称；屏幕阅读器仍可理解昵称的点歌人语义。
- 正常同步使用按钮状态和短暂反馈，不长期占用一行“已同步”。需要用户处理的异常、结果待确认及危险操作的核心后果仍应清楚呈现。
- 保留表单可访问名称与有效的校验反馈，不依赖占位符作为唯一标签。

## 桌面与手机统一整页滚动

- 公共歌单使用页面作为唯一主要纵向滚动区域，去掉列表固定高度与独立纵向滚动框。
- 桌面保留适配的侧栏，手机保留底部导航；列表、标题及操作栏在各视口中保持清晰，无横向溢出。
- 长列表继续虚拟化，支持切页恢复位置、新点歌曲定位与播放指示定位。
- 当前依赖 `@tanstack/react-virtual` 3.14.13 的类型已确认提供 `useWindowVirtualizer`；优先使用现有能力，不为整页虚拟化引入新包。
- 定位后目标歌曲应完整可见并短暂高亮，不被导航遮挡。尊重减少动态效果的系统设置。

## 网易云歌单名称同步

- 进入歌单页、手动同步及必要操作读回取得有效结果时，同时更新云端名称、歌曲集合与顺序。
- 详情使用最近成功读取的网易云名称；房间改名不自动修改网易云歌单名。
- 读取失败保留最后成功歌单快照与名称，反馈本次未更新。旧请求不得覆盖新绑定或较新的读取结果。
- 歌单内容和名称维持按需同步；播放记录的周期读取不隐式变成整份歌单的周期读取。

## 下一首播放

### 权限与交互

- 房主与室友均可对公共歌单歌曲使用“下一首播放”；个人歌单权限不因此扩张。
- 每首歌曲后直接显示“下一首播放”按钮，点击即提交将所选歌曲移至播放指示歌曲紧后方的操作。
- 不提供拖动把手、任意位置排序、“移动到…”入口或额外本地播放队列。
- 例如 `[A, B, C, D]` 中 A 带播放指示，点击 D 后云端目标顺序是 `[A, D, B, C]`，其余歌曲的相对顺序保持。已有下一首再执行不产生重复歌曲。
- 当前播放指示歌曲和已经位于其紧后方的歌曲无需移动，按钮禁用。锚点位于歌单末尾时，将其他所选歌曲移动到它之后。
- 没有可用播放指示或锚点不在公共歌单时，所有“下一首播放”按钮保留并禁用，不按歌单第一首猜测锚点。
- 提交后显示处理状态，结果以云端读回为准；在读回前不将浏览器预览当成已确认顺序。
- 同一成员在该房间最多一个未完成写操作；服务端自身的冲突操作按同一目标协调，沿用原受理限制。

### 冲突与确认

- 命令表达所选歌曲、点击时的播放锚点和所依据的歌单版本/顺序，不开放任意排序指令。
- 沿用用户已确认的冲突规则：执行前读取当前云端歌单并核对播放指示。锚点、歌曲集合或顺序已变化时更新展示，提示用户重新操作，不悄悄改用另一首锚点或覆盖旧整表顺序。
- 移动不得增加、删除或恢复歌曲；成功表示有效云端读回确认所选歌曲紧随锚点，并确认集合保持，不能只看接口响应。
- 官方客户端的外部修改无法由本地串行化消除。执行前核查不能宣称实现网易云原子条件写入，也不能承诺官方客户端当前播放队列跟随变化。
- 请求可能已发送而结果未知时，持久保留确认信息，只读补查，不自动重发，不显示已成功。
- 退出、移除成员、删房、授权失效或换绑沿用原权限与旧结果隔离规则。

### 接口验证

- 固定 Enhanced 的 `song_order_update.js` 存在，接收 `pid`、`ids`，向 `/api/playlist/manipulate/tracks` 发送 `op: update`。按钮仍需真实云端顺序写入；取消拖动交互不取消该接口的验收要求。
- 扩充受审 vendor、adapter schema、完整性清单与写操作分类时继续遵循固定源码、逐次隔离、显式凭据和未知写入不重发规则。
- 验证完整与局部 ID 列表、外部增删及重排时的集合保持行为；不在缺乏证据时假设接口是原子移动或忽略外部变化。
- 不为本功能引入拖放依赖。

## 直接搜索结果扩展

### 已核查事实

- `worker.cts` 对直接搜索写死 `limit: 5, offset: 0`，返回时再次 `slice(0, 5)`；`protocol.ts` 的搜索输出限制为最多 5 首。
- `SongSearchService` 和 `SongRequestDrawer` 没有翻页命令或加载更多入口，页面展示服务端返回的全部歌曲，结果少不是列表在浏览器隐藏了其余条目。
- 已有受审 `cloudsearch.js` 支持 `limit` 和 `offset`，模块默认数量为 30；扩展不需要另加搜索 SDK 或依赖。
- 历史规格的每行前五候选用于文本导入，不能直接当作直接搜索只能显示五首的需求依据；本次只扩展直接搜索，文本导入规则不变。

### 已确认分页规则

- 首次搜索返回最多 20 首，底部提供“加载更多”，每次再取最多 20 首，追加展示并按歌曲 ID 去重。
- 保持网易云返回的相关性顺序，搜索歌名或歌手均返回歌曲，不新增歌手分类页或播放器。
- 只在用户明确点击搜索或加载更多时请求，不自动预取所有分页；加载期间防止重复请求。
- 修改关键词提交新搜索时清除旧候选和选择，隔离旧轮分页及晚到结果；每一轮只浏览同一组关键词。
- 加载更多失败保留已有结果与位置，允许用户明确重试该页；无更多结果时停止继续加载，不把已加载数量说成全站结果总数。
- 翻页仍核对成员、公共歌单绑定及房主授权，使用现有账号调度与限流；旧账号或已撤销成员的结果不能用于新会话。

## 播放指示与定位

### 数据与呈现

- 使用房主当前授权网易云账号 `/record/recent/song` 返回的第一条歌曲记录，按网易云歌曲 ID 匹配当前房间公共歌单。
- 匹配成功时在该歌曲前显示动态音频图标，上方提供“定位到正在播放”按钮；点击后滚动到对应歌曲并短暂高亮。
- 不显示“房主最近播放”常驻说明，不增加播放进度、倒计时或推算的下一首状态。
- 该功能的领域术语为“播放指示”，以账号历史记录作为近似依据；不声称接口提供指定设备实时播放或暂停状态，详见 [ADR-0001](../../docs/adr/0001-playback-indicator-from-recent-record.md)。
- 无记录或最新歌曲不在当前歌单时不显示动态图标；定位按钮继续显示但禁用。只匹配第一条记录，不搜索更早历史寻找一首本歌单歌曲，不展示其他歌曲，也不自动向歌单添加歌曲。

### 更新与失败

- 进入公共歌单页立即读取；页面可见时每 30 秒更新播放记录。切到其他功能页或浏览器后台时停止，回来立即读取。
- 同一真实网易云账号的多成员、多标签页及多房间请求由服务端合并，共享读取结果，不随查看人数倍增上游周期请求。
- 点击“同步歌单”同时发起歌单与播放记录更新，操作期间明确显示正在同步；两项结果分别处理，不因其中一项失败清空另一项成功数据或假报全部已更新。
- 记录读取失败时隐藏活动图标，保留并禁用定位按钮，仅显示简短失败反馈；后续正常读取恢复指示。
- 原账号授权不可用、风控暂停或访问资格撤销时停止相关请求并清除可用指示，不把旧账号结果用于新绑定。
- 周期读取仍通过既有上游调度与限流。30 秒是已选初始工作点，不是经实测确认的上游安全阈值或实时性承诺。
- 浏览器可用 JSON 查询更新 read model，SSE 仍只承载经鉴权的资源失效通知；不增加独立服务或长期 worker。

## 验收

1. 全站页面与弹窗无重复的大标题、点歌人前缀及无意义正常状态占位；数字房间名语义清楚。
2. 点歌旁信息按钮消失，房间设置可查看成功同步后的最新云端歌单名。
3. 手机及桌面长歌单均只有页面纵向滚动；切页恢复、触屏滑动、键盘浏览及横向边界正常。
4. 网易云外部改名后，进入或手动同步更新名称；失败保留旧值，旧响应不覆盖新结果。
5. 歌曲后有“下一首播放”按钮；操作后所选歌曲紧随播放锚点，其余歌曲相对顺序保持；当前歌曲与已是下一首不触发写入，无拖动或任意位置排序入口。
6. 云端实际集合不因移动变化，锚点或歌单冲突时刷新并要求重新操作，未知写入不重发；越权与旧成员/旧绑定结果不可生效。
7. 最近记录第一条匹配歌曲时有动态图标，定位可到达视口外的虚拟行；无记录、无匹配及读取失败时图标消失，按钮保留并禁用。
8. 可见时每 30 秒更新，切页/后台停止，返回及手动同步更新；多人共用同账号不增加重复上游读取；暂停及授权撤销仍有效。
9. 验证直接搜索每页数量与加载更多、同 ID 去重、新关键词隔离旧结果、分页失败保留前页及已无更多结果；文本导入前五候选规则不扩张。
10. 核查减少动态效果、焦点顺序、可访问名称及禁用状态。
11. 完成相关单元/集成、浏览器与 vendor 离线契约验证，并对专用测试歌单完成必要真实接口验收；未完成的验收须明确记录，不能用模拟测试替代真实上游语义证据。
