# Spec: 桌面宽屏栅格布局与信息密度优化 (desktop-grid-density)

## 背景与痛点

在 1920*1080 电脑屏幕下，用户反馈创建房间界面中的播放源账号、网易云详情、QQ 音乐占位、房间名称、我的房间昵称等元素采用单一垂直纵向排列，导致右侧产生大面积空白，视觉比例失衡，信息密度严重偏低。

经全局排查，该类“宽屏下单列纵向堆叠、右侧留白一大块、空间利用率低”的视觉缺陷在全站另外两处也同样存在：
1. **全站账号与身份详情展示框 (`.netease-identity`)**：包括账号设置页 (`/account`)、重新扫码核验流程，以及房间成员列表中的成员详情面板。默认单列垂直排布，导致很短的文本横跨全宽灰框，纵向过长且右侧大片灰色空白。
2. **房间工作区「房间设置」面板的基本信息修改区 (`.room-settings-cards`)**：在宽达 900px+ 的工作区主栏中，“修改房间名称”与“修改房间昵称”分别作为两个单输入框卡片垂直上下堆叠，不仅输入框被过度横向拉扯，上下滚动负担也过重。

## 目标

1. **创建房间页 2 列栅格体系重构**：
   - 播放源平台选择磁贴 (`.playback-source-list`) 采用 2 列等宽 Grid，网易云与 QQ 音乐等高拉伸并排，保留左侧 Radio 语义控件。
   - 房间基础信息表单（“房间名称”与“我的房间昵称”）在桌面端采用 2 列 Grid 并排。
   - 底部保留稳固的全宽主操作按钮，`<= 700px` 响应式平滑降级为单列。
2. **全站账号与身份键值框双列紧凑栅格重构 (`.netease-identity`)**：
   - 将通用 `.netease-identity` 默认改造为双列 Key-Value 网格（昵称在左 50%，账号 ID / 角色在右 50%）。
   - 纵向高度减半，紧凑饱满，在账号设置页、建房卡片和成员详情页保持一致体验。
3. **房间设置面板基本信息修改双列网格重构 (`.room-settings-cards`)**：
   - 将基本信息区域的两张修改卡片改造为双列网格并排（`repeat(2, minmax(0, 1fr))`）。
   - 桌面端平铺两列，小屏平滑折叠，使 900px+ 宽度下的信息布局自然充实。
4. **多端视口适配与自动化无障碍回归**：
   - 统一遵循 `@media (max-width: 700px)` 响应式断点。
   - 在 1920x1080、1440x900、1024x768、375x667 全视口下保持视觉平衡，且通过无障碍（a11y）扫描与已有端到端测试。

## 非目标

1. 不修改任何服务端 API、数据契约、状态机或认证逻辑。
2. 不重构全站大容器（如 `.rooms-page` 820px 基线或 `.main-content` 1180px/1280px 基线）。
3. 不更改平台授权的业务收口规则（未绑定网易云账号时依然保持通栏提示并阻断建房）。
