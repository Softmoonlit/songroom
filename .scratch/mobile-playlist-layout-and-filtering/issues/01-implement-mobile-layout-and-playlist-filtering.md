# 实现移动端排版收敛与歌单列表搜索筛选

Type: implementation
Status: resolved

## 范围

落实用户确认的[完整规格](../spec.md)，实施以下内容：
1. **移动端上半部分排版收敛**：双行紧凑布局，首屏露出更多歌单项，隐藏冗余的 `<h1>公共歌单</h1>`，右侧空白充分利用。
2. **房间标题视觉层级规范化**：`房间：<房间名>` 格式，“房间：”字号偏小颜色次要，房间名粗体大字突出；跨端同步至桌面端左侧边栏。
3. **移动端表头明确“歌曲 / 点歌人”**：更新表头文案，保留歌名下方紧凑胶囊徽标。
4. **歌单列表搜索与点歌人筛选**：
   - 工具栏折叠式搜索图标与平滑展开/收起；
   - 纯文本匹配歌名与歌手（不搜专辑，无自动补全下拉）；
   - 下拉菜单（Select）按点歌人筛选；
   - 复合 AND 过滤、匹配计数、一键清除、保持网易云绝对物理序号。
5. **点歌写入与播放排序维持现状**：遵循系统单写核心原则，维持网易云原生入单逻辑。

## Comments

### 前端重构与歌单搜索筛选实现

1. **移动端双行紧凑头部与房间标题层级**：
   - 重构了 `RoomWorkspace.tsx` 中的房间上下文区域，采用 `<span class="room-prefix">房间：</span><span class="room-name">{room.name}</span>`，移动端在 `320px~768px` 视口下通过弹性排布与右侧身份胶囊对齐成单行，消除了原本右侧三分之二的空白；
   - 歌单工具栏紧凑化，移动端通过 `.sr-only` 视觉裁剪隐藏冗余的 `<h1>公共歌单</h1>`（保留屏幕阅读器无障碍语义），歌曲总数与操作按钮横向排列，使首屏列表项高度压缩 70% 释放出更多歌曲展示空间。
2. **移动端表头文案与点歌人标识**：
   - 移动端列表表头文案由“歌曲与歌手”变更为“歌曲 / 点歌人”，桌面端保持“歌曲与歌手”和“点歌人”独立两列；
   - 列表项歌名下方保留紧凑的点歌人胶囊徽标，避免强行挤入 4 列导致文字截断。
3. **歌单列表纯前端即时搜索与点歌人下拉筛选**：
   - 工具栏新增放大镜图标按钮 `🔍`，点击在列表上方平滑展开/收起搜索筛选栏；
   - 搜索框即时模糊匹配歌名与歌手（不搜专辑名）；
   - 下拉菜单（Select）动态聚合当前歌单全部唯一的点歌人昵称；
   - 复合 AND 过滤，筛选激活时动态显示 `筛选出 X / 共 Y 首` 统计及一键清除按钮；
   - 筛选后歌曲项严格保持网易云歌单中的物理绝对序号（`track.position + 1`）；
   - 修正了过滤视图下“下一首播放”禁用判定：使用真实 `track.position === playback.anchorIndex + 1` 物理判定，不受过滤后索引影响。
4. **CSS 规范与过渡动效**：
   - 增加了 `.playlist-filter-bar` 平滑下滑展开动画，并在 `@media (prefers-reduced-motion: reduce)` 中完全关闭动效；
   - 整理并清除了末尾重复规则，确保 `320px`、`390px` 极窄屏下展开搜索筛选无任何横向溢出。
