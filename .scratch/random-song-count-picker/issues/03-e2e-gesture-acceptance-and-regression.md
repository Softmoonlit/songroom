# 03: 全链路端到端手势验收与零回归验证

**What to build:** 使用 Playwright 在桌面视窗与移动端视窗下完成随机点歌首数滚轮选择器的完整端到端手势交互验收与全业务流程回归。自动化测试覆盖鼠标滚轮滚动、触摸滑动手势吸附、首数边界限制、默认 20 首生成预览、候选不足差额提示以及最终全量旧歌替换，确保全站功能无任何退化。

**Blocked by:** 02: 滚轮手势精细化、渐隐动效与边界防穿透

**Status:** resolved

- [x] 桌面端 E2E：模拟在首数滚轮区域悬停并触发 wheel 滚轮事件，验证中心高亮数值由默认 20 正确滚动增减，`aria-valuenow` 同步更新。
- [x] 移动端 E2E：在移动端视窗模拟 touchstart/touchmove/touchend 滑动手势，验证滚轮容器产生位移并吸附到目标数值。
- [x] 边界测试 E2E：验证向上滚动不能小于 10 首，向下滚动不能超过 50 首，边界处不产生页面抖动或穿透滚动。
- [x] 业务闭环 E2E：选择参与成员后以自定义首数（如 25 首）生成预览，验证预览列表数量、成员贡献分布正确；点击“确认替换”后公共歌单歌曲及点歌人标签完整更新。
- [x] 候选不足 E2E：当所选成员总歌曲数不足指定首数时，界面清晰展示实际首数与不足提示，且不阻断后续确认替换。
- [x] 全量测试套件（单元测试、集成测试、E2E 测试与类型检查）全部通过，无构建或运行时警告。
