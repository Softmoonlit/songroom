# 02: 滚轮手势精细化、渐隐动效与边界防穿透

**What to build:** 为滚轮选择器提供拟物化的物理触感、视效美化及边界隔离防护。在桌面端光标移入滚轮区域时，直接滚动鼠标滚轮平滑步进；在移动端优化 touch 触摸滑动与惯性吸附手感；为滚轮视窗添加上下淡出渐变蒙版和中心选中指示线；同时配置严格的 `overscroll-behavior: contain` 并在 10 与 50 边界拦截滚轮事件冒泡，防止晃动背景弹窗与页面；补全标准无障碍 spinbutton 语义与键盘操作。

**Blocked by:** 01: 契约放宽与滚轮选择器核心贯通

**Status:** resolved

- [x] 桌面端监听滚轮区域的 `onWheel` 事件，滚动鼠标滚轮平滑增减数值，步长为 1，不出现跳帧或剧烈跳动。
- [x] 移动端触控滑动具备平滑的原生惯性与减速，松手后精准吸附居中对齐到最近的整数字。
- [x] 滚轮视窗保持约 3 行可见高度，上下边缘应用渐变渐隐遮罩（Fade Mask），中心行呈现高亮选中指示框与“首”单位文本。
- [x] 容器设置 `overscroll-behavior: contain`，当数值达到最小值 10 或最大值 50 时，继续滚动鼠标滚轮或滑动均被拦截阻止，不触发外部弹窗或底层页面的跟随滚动。
- [x] 交互全程不唤起移动端系统软键盘，弹窗位置保持稳定居中。
- [x] 滚轮容器标记 `role="spinbutton"`，正确绑定 `aria-valuenow`、`aria-valuemin="10"`、`aria-valuemax="50"` 和 `aria-label="期望抽选首数"`，支持使用键盘方向键（↑ / ↓）单步微调。

## Comments

### 实现与验证记录
1. **滚轮平滑阻尼与手势调度**：
   - 在 `WheelPicker.tsx` 中采用非 passive 的原生 `wheel` 监听，拦截事件冒泡与默认滚动，使用阈值累积步进机制，使每一次鼠标滚轮 notch 或触控板滑动平滑步进 1 首，不产生跳帧或暴冲。
   - 在 `min`（10）和 `max`（50）边界处调用 `e.preventDefault()` 严格阻断冒泡，杜绝父级弹窗和背景页面的联动晃动。
2. **拟物视效与淡出蒙版**：
   - 配置 `-webkit-mask-image` 与标准 `mask-image` 的透明渐变遮罩，使数字在滚入与滚出上下视窗边缘时自然淡化渐隐。
   - 中心高亮指示层配置淡主色背景与精细上下边框，并在右侧固定展示“首”单位。
3. **触控与无障碍**：
   - 移动端依托原生 `overflow-y: scroll` 与 CSS `scroll-snap-type: y mandatory`，提供丝滑的原生惯性与居中吸附。
   - `role="spinbutton"` 绑定于滚动视窗，满足键盘方向键操作（↑/↓/PageUp/PageDown）以及 WCAG / Axe 无障碍规范（`scrollable-region-focusable` 全绿通过）。
   - 纯手势与滚轮操作，无输入框聚焦，移动端不弹起软键盘。
