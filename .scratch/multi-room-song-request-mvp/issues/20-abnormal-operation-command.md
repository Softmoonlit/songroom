# 20: 通过管理命令处置异常操作

**What to build:** 让具权服务器管理员查看并处置具体的未知写入、未知创建、公共清理和风控暂停，同时把每种高风险动作限制在已确认的业务规则内。

**Blocked by:** 11/恢复未知歌曲写入而不重发、12/处理公共歌单创建结果未知、18/恢复结果未知的公共歌单清理、19/通过管理命令恢复点歌台账号

**Status:** ready-for-agent

- [ ] 管理命令复用具权 HTTPS 登录、隐藏 TTY 输入、Cookie jar、精确 Origin、证书校验和退出清理，不提供网页管理后台、任意 SQL 或任意 Enhanced 调用入口。
- [ ] 管理员只能按具体内部操作 ID 查看脱敏异常事实；列表、详情和命令不返回凭据、请求体、原始上游响应或不相关用户数据。
- [ ] 普通歌曲写入长期未知只能终结为“结果未能确认”并解除目标阻塞，不宣称失败、不回滚、不补写；后续业务必须先刷新并使用新幂等键。
- [ ] 创建未知只能记录核查结论：具体 ID 证据唯一且原业务仍有效时恢复绑定，业务已结束时转公共清理，证据歧义时继续暂停；不得按名称猜测或再次创建。
- [ ] 公共删除未知只有在核实原具体目标仍存活且仍应清理后，才允许明确授权一次新的删除尝试；授权是单次、持久且不能被重复消费。
- [ ] 上游明确拒绝后，管理员可记录房主已在原账号官方客户端手工处理并触发服务端只读核验；证据不足时保持清理任务。
- [ ] 风控暂停只有管理员可明确恢复；执行时重新核实当前真实账号、授权、暂停原因和状态，不能用重新授权或重启隐式恢复。
- [ ] 每个高风险动作显示原账号、具体目标、当前状态和影响，要求原因及明确确认；原因去除首尾空白、规范为 Unicode NFC、拒绝控制字符且为 1 至 500 个码点，执行前重新读取，任何状态变化均拒绝旧确认。
- [ ] 高风险审计记录管理员、目标、动作、原因、前后状态和结果，日志仍不含昵称、歌曲、凭据、Cookie 或完整错误响应。
- [ ] 集成测试覆盖无权拒绝、普通未知终结、创建证据唯一/歧义、单次删除授权、防重复消费、手工清理核验、风控恢复和确认竞态。
