# 15: 退出授权并以同账号重新授权

**What to build:** 让房主主动退出、遇到失效授权或凭据主密钥丢失后暂停其全部自建房间的上游工作，并通过扫码重新核实同一个真实网易云账号来恢复既有公共配置及安全的未发步骤；第一期不允许借此更换账号。

**Blocked by:** 11/恢复未知歌曲写入而不重发，12/处理公共歌单创建结果未知

**Status:** resolved

- [x] 只有绑定所属的点歌台用户可退出及重新授权自己的网易云账号；室友、待审批者、其他房主和普通管理员不能替其发起或完成流程，室友在该用户房间内的操作仍始终使用房主授权而非自己的授权。
- [x] 主动退出授权要求明确确认，并立即使该用户全部自建房间的上游操作进入等待授权；房间、成员、邀请、公共绑定、最后确认快照、点歌标签和该用户作为室友加入的其他房间均保留，退出点歌台会话与退出网易云授权保持两项独立动作。
- [x] 重新授权流程绑定发起点歌台账号、发起 Better Auth 会话、有效期和流程代次；替代流程使旧流程失效，会话到期、跨账号读取、跨会话完成、伪造真实账号 ID 或晚到二维码结果均不能提交凭据。
- [x] 服务端从扫码结果核实真实网易云账号；只有与原绑定账号完全一致才接受新凭据代次，不同账号明确拒绝且不修改旧绑定、任务或房间，第一期界面不提供账号更换确认、数据清理或迁移入口。
- [x] 凭据主密钥丢失、替换或旧密文无法解密时，系统停止相关上游功能但保留房间、成员、公共绑定、快照和未解决任务；安装新的有效主密钥后，用户可扫码核实原真实账号并把新凭据写入新代次，不能用另一个账号接管旧配置或清理。
- [x] 同账号凭据恢复后，包括密钥事故后的恢复，所有可能已发的歌曲写入和公共创建先进入只读核查，绝不重发；尚未发步骤重新核验成员资格、房主关系、公共绑定、目标及冲突后才自动继续，已失效意图停止，创建未知只刷新证据而不猜测关联。
- [x] 原账号重新授权可启动新的只读确认轮次并继续合法的尚未发送步骤，但不能自动解除风控暂停、目标权限暂停或管理员处理状态；这些状态在界面与机器码中保持可区分。
- [x] 旧凭据候选、旧授权代次和退出前晚到响应不能覆盖新凭据或新快照；重新授权与退出并发时只有当前流程代次可提交，任何结果都不能写入另一个真实账号或新目标。
- [x] 房间列表、账号授权页、公共歌单页和当前操作入口向房主及房间成员显示等待授权、正在核实、账号不匹配、已恢复和仍需管理员处理的准确状态；二维码只在发起者授权页面临时显示且不进入 URL、持久草稿或日志。
- [x] 服务重启保留退出状态、原账号身份、未解决操作和流程代次边界；可丢弃未完成二维码展示并要求重新发起扫码，但不得因重启自动生成凭据、恢复授权或删除任务。
- [x] 自动化通过真实认证和运行中的同源应用，经公开退出/扫码/授权状态/操作查询端点及浏览器页面，使用脚本化 adapter 覆盖同账号成功、错误账号、替代流程、跨会话、凭据主密钥丢失后安装新密钥并恢复原账号、排队未发创建的停止与安全继续、旧凭据晚到、未知写入与未知创建只读核查；测试不得直接注入业务表状态或绕过公开授权契约。
