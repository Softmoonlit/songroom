# 07: 安全创建公共歌单

**What to build:** 让房主按需为房间创建一份专用公共网易云歌单，并通过持久、幂等的异步操作看到创建进度和明确返回 ID 后的最终绑定。

**Blocked by:** 03/安全扫码绑定网易云账号、04/创建、列出并进入房间

**Status:** resolved

- [x] 建房和审批成员不自动创建歌单；只有房主可在尚无公共绑定且授权有效时明确发起创建。
- [x] 公共歌单是当前房间专用资源，不能绑定已有歌单、与其他房间共用或仅凭名称推断归属；创建名称遵循规格且后续改房名不自动改云端名称。
- [x] 创建命令使用按点歌台账号定域的 UUIDv7 幂等键和规范请求摘要：同键同内容返回原操作，不同内容、过期或来自未来的键明确拒绝。
- [x] 命令先在本地事务保存封闭创建意图、原真实账号、凭据代次、房间和发送状态，再返回异步操作；数据库事务不跨越上游调用。
- [x] 上游正常返回具体歌单 ID 后，系统在重新核验房间、房主、授权和目标状态后建立唯一公共绑定，并在页面显示成功。
- [x] 进入发送状态后的异常一律保存为可能已发且不自动再次创建，完整核查与恢复由 ticket 12 承接；授权退出、房间删除等后续生命周期动作分别在拥有公开动作的 tickets 15、17 验收尚未发送步骤的停止。
- [x] 一个房间并发创建只有一个受理结果；重复点击返回同一操作，不能生成多份公共歌单。
- [x] 当前操作 read model 区分排队、处理中、待确认、等待授权、需管理员处理、成功、明确失败和已停止，不将待确认展示为失败或可重试。
- [x] 浏览器只能提交房间内业务意图，不能指定真实账号、凭据、任意歌单 ID、锁键、内部步骤或 Enhanced 模块名。
- [x] 真实临时 SQLite 集成覆盖受理事务、幂等、并发唯一、正常 ID 绑定和发送后中断不重发；多账号公平调度、创建未知及后续生命周期停止分别由 tickets 08、12、15、17 承接。
