# 35: 恢复个人资源的未知清理

**What to build:** 让室友个人歌单创建结果未知以及成员退出、删房或换号遗留的个人专用歌单清理，按原账号、具体目标和当前生命周期安全收敛，并复用第一期成熟的人工处置边界。

**Blocked by:** 15/退出授权并以同账号重新授权、31/处理个人歌单失效与重配置、32/破坏性更换网易云账号、34/扩展删房清理个人资源

**Status:** ready-for-agent

- [ ] 室友专用个人歌单创建 ID 未知时，扩展既有具权管理命令核对创建意图、创建前后完整清单、创建者和具体候选；唯一证据且原成员、房间和绑定资格仍有效时恢复该具体 ID 的个人绑定，生命周期已结束时转为该具体目标的最小个人清理，证据歧义时继续暂停。
- [ ] 管理员不得按名称、日期、昵称或“最新歌单”猜测个人创建结果，也不得再次创建；浏览器和普通用户不能提交候选 ID、直接认领目标或绕过具权核查。
- [ ] 每个已确定具体 ID 的室友专用个人歌单删除在调用前独立持久化发送意图；进入发送状态后的超时、崩溃、异常退出或解析失败只确认不自动重发。
- [ ] 补查使用创建该资源的原真实网易云账号、具体云端 ID、完整清单和固定墓碑契约，不通过名称、旧昵称或新成员关系猜测目标。
- [ ] 清理记录只保留原账号、具体目标、专用创建证据、凭据归属、发送状态和确认信息，不保存成员昵称、歌曲快照、标签、导入原文或旧成员档案。
- [ ] 原账号授权缺失时跨重启等待；同账号重新授权后恢复只读确认，新绑定账号、重新加入后的成员或新创建歌单不能被用于旧清理。
- [ ] 明确业务成功、已验证删除墓碑、明确拒绝、普通读取失败、502 和证据矛盾保持不同状态，不将任意异常当作删除成功。
- [ ] 长期删除未知通过既有管理命令核查；只有证明具体旧目标仍存活且仍应删除时，才允许一次新的专用删除授权并防止重复消费。
- [ ] 原账号官方客户端手工删除后可由管理员触发只读核验，证据满足时完成任务；管理员不能直接指定另一个删除目标或调用通用上游模块。
- [ ] 旧清理完成后移除最小任务，不影响重新加入后新建的个人歌单、其他成员资源、公共歌单或房主共享个人绑定；原真实账号的最后一份有效绑定和未解决任务均终结后释放全站归属，另一点歌台账号才可重新扫码绑定它。
- [ ] 多个清理任务公平使用账号调度，一个目标待确认不应阻塞不同目标的允许操作，但同目标冲突保持阻塞。
- [ ] 确定性测试覆盖个人创建候选唯一后恢复绑定、生命周期结束后转清理、候选歧义继续暂停、每个删除崩溃切点、多任务、账号换代、同账号重授权、墓碑旧歌曲、手工清理、单次重试、新旧资源隔离，以及最后绑定和任务终结前拒绝、终结后允许另一点歌台账号绑定原真实账号。
