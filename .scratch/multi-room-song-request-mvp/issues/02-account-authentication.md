# 02: 完成点歌台账号闭环

**What to build:** 让用户通过 Better Auth 的原生邮箱密码流程注册、登录和管理自己的点歌台账号，并在手机与电脑上恢复同一账号及后续业务身份。

**Blocked by:** 01/建立可运行的同源应用

**Status:** resolved

- [x] 首次访问者可用账号称呼、邮箱和密码注册，注册成功后按 Better Auth 原生流程自动登录并进入自己的房间列表。
- [x] 邮箱只作为唯一登录标识且不进入房间 read model；账号称呼可重复、可修改，不提供唯一用户名、改邮箱、邮箱验证、验证码或邮件找回入口。
- [x] 固定 Better Auth 版本的密码范围、生产限流、7 天会话有效期、1 天续期间隔和滚动续期通过接入测试复核，不增加自定义锁定、持久认证计数或双重会话期限。
- [x] 同一账号可同时保有多个设备会话；退出只结束当前会话，不删除业务数据或影响其他设备。
- [x] 主动改密要求当前密码，并保持组件默认的不自动撤销其他设备会话行为。
- [x] 全站最多创建 100 个点歌台账号；达到上限只拒绝新注册，已有账号仍可登录和使用。
- [x] 使用数据库会话和原生签名 Cookie，不启用 Bearer 或 Cookie 会话缓存；Cookie 具备 HttpOnly、Secure 和与可信同源入口一致的属性。
- [x] 忘记密码流程只说明通过既定线下渠道联系服务器管理员；本票不实现邮件找回、临时密码或后续具权管理恢复命令。
- [x] 认证页面与账号页面支持键盘操作、可见焦点、清楚错误反馈以及 320px 起的响应式布局，不泄露账号是否存在之外的额外业务信息。
- [x] HTTP 集成测试覆盖注册自动登录、重复称呼、重复邮箱、错误密码、限流、改密、多设备会话、当前会话退出、会话续期和过期后重新登录，日志不出现密码、Cookie、邮箱、账号称呼或原始敏感错误。
