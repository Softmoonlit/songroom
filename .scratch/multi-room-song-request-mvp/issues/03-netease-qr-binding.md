# 03: 安全扫码绑定网易云账号

**What to build:** 让已登录用户在自己的有效会话中扫码授权网易云，核实并确认真实账号身份后建立一份可供其全部自建房间复用的服务端授权。

**Blocked by:** 02/完成点歌台账号闭环

**Status:** ready-for-agent

- [ ] 仓库纳入规格固定版本与源码哈希的 NeteaseCloudMusicApiEnhanced vendor、许可证、来源说明和锁文件，生产不会联网下载替代版本。
- [ ] vendor 生产补丁移除歌曲增删特定路径的二次写、隐式 `NETEASE_COOKIE` 来源和敏感原始错误输出，并修复二维码检查遮蔽原错误的问题；完整性检查可检测任何偏离。
- [ ] 生产 adapter 只暴露批准的白名单业务能力；每次调用使用独立短命子进程、0700 一次性目录、严格 umask、最小环境和显式凭据，退出后清理目录且不接入原始 stdout/stderr。
- [ ] IPC 输入输出均由 schema 校验，worker 只返回脱敏结构；账号为空、核实账号不匹配、授权不可用、目标权限错误、风控或频繁请求、网络错误、普通模块错误、截止、异常退出和解析失败保持可区分的稳定类别，候选凭据只有在身份与授权代次仍匹配时才可提交。
- [ ] 每个扫码流程有有效期、单次使用并绑定发起点歌台账号、发起 Better Auth 会话和流程代次；替代流程、过期流程、会话失效及跨账号读取或完成均被拒绝。
- [ ] 浏览器只能查看自己当前流程的临时二维码和状态，不能声明或覆盖真实网易云账号 ID；服务端以扫码后的身份接口核实结果并在最终确认前展示真实身份。
- [ ] 一个点歌台账号同时最多绑定一个网易云账号，同一真实网易云账号不能同时归属两个点歌台账号；并发完成时由数据库约束保证唯一结果。
- [ ] 网易云凭据使用 Node.js AES-256-GCM 逐条加密，随机 nonce，并以授权 ID、真实账号 ID 和凭据代次作为附加认证数据；主密钥来自受限私有文件。
- [ ] 首次绑定后再次扫到另一个真实账号必须拒绝并保留原绑定；主动退出、同账号重授权和破坏性换号分别由后续 ticket 实现，本票不提前暴露这些动作。
- [ ] 离线 adapter 契约证明私有目录、最小环境、显式 Cookie、硬截止、脱敏及每个白名单写步骤最多一次出站写请求；完整应用测试覆盖扫码成功、替代、过期、跨会话、伪造 ID、重复归属和并发完成。
