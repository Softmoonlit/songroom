# 25: 创建并查看室友个人歌单

**What to build:** 让当前室友按需在房主网易云账号下创建一份仅属于自己和当前房间的专用个人歌单，并让房间成员从成员详情只读查看。

**Blocked by:** 06/审批成员并管理房间身份、08/有界且公平地执行上游操作、11/恢复未知歌曲写入而不重发、12/处理公共歌单创建结果未知、23/执行第一期真实上线验收、24/绑定并查看房主个人歌单

**Status:** ready-for-agent

- [ ] 室友获批时不自动创建个人歌单；只有该室友可在“我的歌单”明确发起创建，且不要求绑定自己的网易云账号。
- [ ] 创建始终使用目标房间房主的当前有效授权，名称采用规格格式；后续房间或成员改名不自动改云端名称。
- [ ] 室友只能专用新建，不能绑定已有歌单、收藏歌单、任意公开 ID，不能与其他成员或房间共用该专用目标。
- [ ] 同一当前成员在当前房间至多一个个人绑定；并发创建复用持久操作、幂等、调度和未知创建规则，不产生重复云端歌单。
- [ ] 正常返回具体 ID 后自动建立带专用创建证据的新绑定；已获 ID 未关联按当前成员和房间状态恢复，未知 ID 不按名称猜测或再次创建。
- [ ] 归属室友在 ticket 24 已建立的“我的歌单”入口查看该专用来源，read model 将其标记为可维护；房主及其他成员只能从“房间成员”的成员详情查看只读内容，不能添加、删除或从中点歌，实际单首维护由 ticket 26 实现。
- [ ] 专用个人歌单不与公共歌单共用、不会自动汇总到公共目标；没有公共歌单时仍可独立创建和查看，维护操作由后续 ticket 提供。
- [ ] 页面按需读取权威快照，显示同步时间与失败状态，并复用规范化目标、完整读取和虚拟列表规则。
- [ ] 创建或同步过程中成员撤权、房间删除、授权代次变化和晚到响应不能恢复成员或绑定，必要时只转最小个人资源清理。
- [ ] HTTP、SQLite 与浏览器测试覆盖本人创建、房主/他人越权、无房主授权、并发创建、未知结果、成员撤权和成员详情只读。
