# 10: 搜索并直接公共点歌

**What to build:** 让当前房间成员在公共歌单页搜索网易云单曲、选择候选并提交一次可追踪的公共点歌；系统使用房主当前授权和房间当前公共目标执行写后读回，只有云端歌曲与本人的去重点歌标签都确认后才显示完整成功。

**Blocked by:** 06/审批成员并管理房间身份，08/有界且公平地执行上游操作，09/读取并刷新权威公共歌单快照

**Status:** resolved

- [x] 公共歌单页为房主和室友提供吸顶的直接搜索工具栏、渐进候选状态、取消选择和明确的提交动作；搜索、查看候选和取消均不写云端，320px 起无横向溢出、遮挡或布局跳动，并可只用键盘完成搜索、选歌和提交。
- [x] 直接搜索使用规格固定的 `@fastify/sse` 首次建立经鉴权的账号级失效流，每个登录浏览器只建立这一条 SSE 连接：创建短命内存 `searchId` 后立即返回，候选进度变化只发送最小失效事件并由 TanStack Query 重查；事件不携带搜索词、候选或结果正文。
- [x] 直接搜索点歌不要求、读取、创建或写入个人歌单，第一期界面不出现“我的歌单”、导入、个人来源或更换网易云账号入口。
- [x] 服务端在搜索和提交时都重新校验登录会话、当前成员资格、房主有效授权、当前公共绑定、目标可写性、冲突状态和队列容量；待审批者、非成员、已离开成员及其他房间成员均不能搜索该授权或向该房间点歌。
- [x] 浏览器只能提交搜索选择和封闭的点歌意图，不能指定网易云凭据、真实账号调度键、任意云端歌单 ID、绑定代次或内部步骤；实际调用始终从目标房间及其房主绑定推导。
- [x] 已接受的点歌立即返回可查询的操作资源；同一成员在同一房间已有未完成写操作时拒绝第二项不同写入，同一幂等键和相同内容返回原操作，同键不同内容、过期键或明显来自未来的键以稳定机器码拒绝。
- [x] 公共目标已有该歌曲时不调用增加接口、不移动或重排歌曲，只写入该成员的去重标签；同一成员重复点歌不累计次数，不同成员可分别留下标签，网易云集合和顺序始终以有效完整读回为准。
- [x] 目标尚无歌曲时只发送一次增加请求并执行完整读回；读回确认歌曲存在后才提交标签，歌曲与标签均完成才显示成功，歌曲已确认但标签未完成时分别展示两项状态且后续只能补标签，不能再次增加歌曲。
- [x] 有效完整公共刷新确认某歌曲移除时，在同一事务清除该歌曲的全部成员标签；失败或不完整刷新保留标签，两次同步之间外部删后重加但未被观察到时延续原标签生命周期。
- [x] 外部客户端在核验前后增删同一歌曲时，结果按本次有效完整读回如实收敛；旧快照、旧绑定代次和晚到搜索结果不能覆盖较新的快照、候选轮次或目标状态。
- [x] 搜索是可取消的短命工作，一轮搜索无论包含多少上游请求都只占账号队列一个操作；离开或修改搜索后停止尚未发出的请求并丢弃晚到候选，服务重启后可丢弃搜索并提示重新搜索，已经接受的点歌操作仍可从操作入口读取。
- [x] 界面区分搜索中、未找到、搜索失败、队列繁忙、等待授权、目标阻塞、处理中、歌曲已确认但标签未完成、成功和明确失败，不把上游等待包装成页面卡死或把标签结果包装成云端写入结果。
- [x] 自动化从运行中的同源应用经公开 JSON 搜索、账号级 SSE、点歌命令、操作查询和浏览器页面覆盖立即返回 searchId、渐进候选、正常新增、已有歌曲、同步删标签、重复点击、跨成员标签、权限拒绝及外部竞态，并用脚本化 Enhanced adapter 断言允许的上游调用；测试不得直接修改数据库、调用私有步骤或固定 SQL 和内部函数顺序。
