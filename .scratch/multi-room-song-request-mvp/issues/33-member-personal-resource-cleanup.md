# 33: 扩展成员退出清理个人资源

**What to build:** 将个人歌单、个人来源点歌和导入纳入室友主动退出与房主移除的同一即时清理，并为其专用云端个人歌单留下最小且可恢复的删除责任。

**Blocked by:** 25/创建并查看室友个人歌单、27/批量删除和清空个人歌单、28/从自己的个人歌单点歌、30/提交文本导入并恢复结果、31/处理个人歌单失效与重配置

**Status:** ready-for-agent

- [ ] 室友主动退出和房主移除走同一领域操作，本地事务提交后立即撤销房间权限并拒绝原成员的查询、命令和操作结果访问。
- [ ] 昵称、本人全部点歌标签、个人绑定、快照引用、导入及其他房间内成员业务数据被硬删除且不可恢复，不保留离开档案。
- [ ] 点歌台账号、其他房间、公共歌单歌曲、其他成员标签和房主授权保持不变，旧昵称立即可由后来者使用但不继承数据。
- [ ] 室友专用个人歌单生成仅含原真实账号、具体云端目标、专用创建证据、发送状态和必要确认信息的清理任务，不含昵称、快照、标签、导入原文或候选。
- [ ] 本地清理不等待授权或云端删除；正常删除只使用房主原真实账号和具体目标，并遵守既定调度与账号隔离。
- [ ] 该成员尚未发的个人维护、导入和来源点歌步骤全部停止，已发及晚到结果只能收敛原目标，不能恢复成员、绑定、快照或标签。
- [ ] 专用创建已取得具体 ID 但未绑定时转为该目标清理；ID 未知时保持管理员核查，不能按名称、日期或内容猜测。
- [ ] 删除失败或未知转入 35 的恢复状态而不回滚本地退出；旧 SSE、操作入口和幂等标识不能绕过资格撤销。
- [ ] 同一账号以后通过当前邀请重新申请获批时获得全新成员与绑定代次，不继承旧个人歌单、草稿、标签、操作或清理任务。
- [ ] 自动化覆盖主动退出、房主移除、进行中导入、个人来源点歌、创建竞态、删除失败、晚到响应、跨设备撤权和重新加入。
