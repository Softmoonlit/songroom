# 31: 处理个人歌单失效与重配置

**What to build:** 识别个人歌单的暂时读取失败、权限变化与确认删除，只在证据充分时解除失效绑定，并让归属成员按原类型从空状态主动重配置。

**Blocked by:** 09/读取并刷新权威公共歌单快照、11/恢复未知歌曲写入而不重发、24/绑定并查看房主个人歌单、25/创建并查看室友个人歌单、26/单首维护可写个人歌单、27/批量删除和清空个人歌单、28/从自己的个人歌单点歌、30/提交文本导入并恢复结果

**Status:** ready-for-agent

- [ ] read model 和操作状态区分暂时读取失败、授权不可用、目标权限错误、自建或收藏资格失效、确认删除及删除墓碑，并提供稳定原因与允许动作。
- [ ] 普通网络错误、一次失败或不完整读取保留原绑定、最近快照和同步时间，不自动清空、解除、重建或选择替代目标。
- [ ] 删除墓碑即使仍返回旧歌曲也不能形成有效快照、维护目标或个人来源点歌证据，任意 502 也不能单独证明已删除。
- [ ] 只有满足既定完整读取和目标判定契约时才解除失效绑定，并停止该绑定的添加、导入、删除、清空和来源点歌；直接搜索公共点歌不受阻塞。
- [ ] 室友专用个人歌单确认删除后只能由该室友主动新建；房主来源不可恢复时只能从当前授权账号实际自建或收藏清单重新选择并核验能力。
- [ ] 重配置生成新绑定代次，不按名称猜测、不自动新建替代目标、不从旧快照补歌、不迁移歌曲，也不复用已失效专用目标。
- [ ] 房主解除或更换已有自建及收藏来源只作用于当前房间，不删除云端对象、不取消收藏，也不影响其他房间的有效引用与共享快照。
- [ ] 旧绑定尚未发步骤停止，可能已发步骤只对原账号和原目标确认；晚到读取或写入不能重新挂回旧绑定或覆盖新快照。
- [ ] 破坏性重配置展示影响范围并携带聚合版本，确认期间绑定、任务或资源状态变化时拒绝旧确认并重新读取。
- [ ] 自动化覆盖临时失败、部分读取、墓碑、外部删除、自建资格变化、收藏失效、跨房共享、重配置和晚到响应竞态。
