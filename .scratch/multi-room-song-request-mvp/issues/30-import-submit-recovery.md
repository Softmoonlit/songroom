# 30: 提交文本导入并恢复结果

**What to build:** 让成员把已确认预览提交到自己的可维护个人歌单，逐首按真实网易云结果完成部分成功，并在关页或重启后继续查看已提交操作。

**Blocked by:** 11/恢复未知歌曲写入而不重发、26/单首维护可写个人歌单、29/预览文本导入并管理草稿

**Status:** ready-for-agent

- [ ] 提交命令重新鉴权并捕获成员、房主授权、个人绑定代次和目标可写能力；浏览器候选不能替换服务端推导的实际目标。
- [ ] 成员资格已结束时拒绝并立即清除该房间草稿；成员仍有效但归属、绑定代次、可写性或房主授权变化时明确拒绝且保留当前预览供用户处理。
- [ ] 受理后先完整读取目标，按网易云歌曲 ID 去重并跳过已存在项；多行选中同一 ID 最多产生一次写入，同名不同 ID 可分别存在。
- [ ] 缺少项逐首最多发送一次增加请求并逐首完整读回；整次已提交导入只占账号队列一个业务操作，不按歌曲或上游请求占多项，每次上游请求后公平让出，但同目标冲突步骤不得插入受保护阶段。
- [ ] 明确拒绝记录该项失败后可继续后续项；结果可能未知时暂停同目标后续写入并只读确认，不自动重发未知项。
- [ ] 导入允许部分成功且不回滚，逐项结果区分已加入、已存在、明确失败和待确认；成功只证明读回时歌曲存在，不承诺可播放或由本次首次加入。
- [ ] 同一提交幂等键同内容返回原操作，不同内容拒绝；提交后没有取消，关页、切页或退出不终止服务端操作。
- [ ] 已提交操作从服务端查询并可跨标签页恢复；终结后清除输入、搜索词和候选，只短期保留最小歌曲结果与防重摘要。
- [ ] 目标、成员、授权或绑定在执行中变化时停止尚未发步骤，晚到结果只用于原目标确认，不能恢复旧个人绑定或成员数据。
- [ ] 真实 SQLite 与完整应用测试覆盖去重、混合结果、部分成功、未知暂停、重启、幂等冲突、撤权竞态和结果清理。
