# 22: 交付第一期单机生产运行包

**What to build:** 让平台运营者可以在单台公网 VPS 上以受限系统身份初始化、迁移、自检、启动、停止和升级第一期 SongRoom，并由 Caddy 提供唯一可信公网入口。

**Blocked by:** 21/完成第一期安全负面矩阵

**Status:** resolved

- [x] 生产使用 systemd 运行一个长期 Node.js 应用进程，不使用 Docker、多实例、独立 worker 服务、数据库租约或自动故障切换。
- [x] 应用仅监听本机回环地址，Caddy 是唯一公网入口并提供浏览器默认信任的 HTTPS、精确 Origin、正确代理信任和自动证书续期。
- [x] 持久数据、私有配置和运行临时数据位于彼此分离且权限受限的系统位置；数据库与密钥不在静态资源目录，应用系统用户只拥有必要写权限。
- [x] 凭据主密钥和 Better Auth 签名密钥从稳定受限文件读取，不进入环境变量、命令行、仓库、数据库或日志；缺失、权限错误或解密失败时停止相关功能。
- [x] 启动前自检数据库、schema、密钥权限、固定 vendor 哈希、生产补丁、唯一 HTTPS base URL 和必要配置；任何失败都阻止就绪而不自动建库或迁移。
- [x] 显式初始化、离线迁移和只读检查命令依赖服务器权限但不能修改普通业务状态；升级流程保证应用与前后端原子发布。
- [x] 应用监听成功后才启动唯一调度器，并在就绪后 5 秒工作点内推进可恢复任务；第二实例因端口冲突失败。
- [x] 停机先拒绝新业务命令和上游派发，最多等待当前 25 秒子进程，总停机上限 35 秒；中断的发送步骤重启后只确认不重发。
- [x] systemd 安全限制包含无新权限、只读系统区域和最小必要可写范围；结构化日志由 journald 限量保留且不另建敏感日志平台。
- [x] 精简运维清单覆盖初始化、启停、升级检查、管理员初始化、账号恢复、异常处置、原账号手工清理、风控恢复、密钥缺失和数据库丢失。

## Comments

### 实现说明
1. **部署单元与反向代理基线**：
   - 编写 `deploy/systemd/songroom.service`：配置单实例长期进程、专用系统用户 `songroom`、`KillSignal=SIGTERM`、`TimeoutStopSec=35s`、`Environment=TMPDIR=/run/songroom`、`NoNewPrivileges=true`、`ProtectSystem=strict`、`ProtectHome=true`、`PrivateTmp=true`、只读系统与密钥目录（`/opt/songroom`、`/etc/songroom`、`/var/lib/songroom/private`）、可写目录限制（`/var/lib/songroom/data`、`/run/songroom`、`/tmp`）、无超级用户特权（`CapabilityBoundingSet=`）以及服务级日志速率限制。
   - 编写 `deploy/systemd/songroom-journald.conf`：结构化日志由 journald 限量保留（100 MiB 上限、最长 7 天、速率限制）。
   - 编写 `deploy/caddy/Caddyfile`：唯一步入公网的反向代理，负责自动配置与续期公共受信任 TLS 证书、精确传递代理头、限制 128 KiB 请求体并将所有流量代理至 `127.0.0.1:3000`。邀请链接携带的 fragment 凭据天然不上送服务端与网关日志。
   - 编写 `deploy/songroom.config.production.json`：生产私有配置模板。
2. **安全边界与权限硬化**：
   - 硬化数据库文件权限自检（`assertDatabasePath`）：严格要求属主为当前运行用户、禁止符号链接、可写连接与迁移严格要求 `0600`，只读自检允许 `0600` 或 `0400`。
   - 硬化密钥与配置自检：凭据主密钥与配置文件禁止符号链接，凭据主密钥严格要求 32 字节二进制且属主权限 `0600` 或 `0400`，在 systemd 中私有目录设为只读挂载防篡改。
   - 优雅停机排空机制完善：在 `drain()` 阶段不仅停止调度器接收新任务和派发，还显式停止歌单服务清除所有进行中的补查计时器（`playlists.stop()`），断开 SSE 并关闭 Fastify，等待在途子进程（最长 25 秒），保证 35 秒内优雅完成停机；中断任务重启后只读确认，绝不重发。
3. **运维操作手册与精简运维清单**：
   - 编写 `docs/operations.md`：详细覆盖初始化（受限用户、目录隔离、密钥生成、配置、建库、自检、Caddy 与 systemd 部署）、服务启停与排空（优雅停机与日志查询）、升级检查与前后端原子发布（独立目录构建、离线迁移、软链接原子切换）、管理员声明（交互式查询 User ID 写入白名单）、线下账号人工恢复（交互式核验、双步原子设密与撤销、审计日志）、异常操作处置（列出、详情、终结未知普通写入、核验未知创建、授权专用删除重试）、原账号手工清理核验（官方 App 手动删除后服务端重新核验）、风控恢复（账号级恢复派发）、密钥缺失与灾难换钥恢复（自检失败不隐式重置、启动期自动停止解密失败授权、原账号重新授权唤醒任务）、数据库丢失边界（自检直接失败不隐式建库、全损手工重建边界声明）。
   - 更新 `README.md`：增加生产部署与运维章节索引，说明部署文件包与运维手册。
