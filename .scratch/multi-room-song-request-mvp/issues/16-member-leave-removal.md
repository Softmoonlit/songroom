# 16: 退出或移除房间成员

**What to build:** 让室友主动退出或被房主移除时立即撤销当前房间权限，并彻底清除该成员的昵称、公共点歌标签和成员操作可见数据，同时保留公共歌曲、其他成员数据、点歌台账号与其他房间关系。

**Blocked by:** 10/搜索并直接公共点歌，11/恢复未知歌曲写入而不重发，14/通过 SSE 同步多端状态

**Status:** ready-for-agent

- [ ] 室友可主动退出自己当前加入的房间，房主可在二次确认后移除当前室友；房主不能以室友退出流程离开自己的房间，室友不能移除他人，待审批者、非成员和其他房间房主不能执行任一动作。
- [ ] 退出与移除使用相同的本地原子清理结果：立即硬删除当前成员关系和昵称，删除该成员在当前公共绑定上的全部点歌人标签，并撤销其对房间、公共歌单、成员列表、设置及原操作详情的读取和命令权限。
- [ ] 第一期成员清理只处理成员关系、昵称、公共标签和该成员操作数据，不创建、查找或删除个人歌单、个人绑定、个人快照、导入草稿或任何成员专用云端资源，也不留下相关清理任务假设。
- [ ] 清理不删除或重排公共歌单歌曲，不清除其他成员标签，不删除点歌台账号、其他房间数据或房主网易云授权；旧昵称立即释放，后来者或重新获批者使用该昵称时不继承旧标签、操作结果或其他成员数据。
- [ ] 移除确认携带当前成员/房间聚合版本；确认前成员改名、已经退出、房间状态变化或重复移除时拒绝旧确认并返回最新影响范围，任何并发路径都只能完成一次资格终止。
- [ ] 资格终止立即停止尚未发出的该成员点歌步骤；已经可能发出的歌曲写入只保留收敛公共云端结果所需的最小事实，可更新公共快照但不能补回离开者标签、恢复成员、占用昵称或让其继续查看操作。
- [ ] adapter 晚到响应、标签补记、操作恢复、旧 SSE 事件和浏览器缓存都不能恢复已删除成员数据；资格撤销事务提交后旧请求重新查询均返回资源不可见或权限拒绝。
- [ ] 服务重启后不存在可恢复的离开档案；重新加入必须使用当前有效邀请重新申请并由房主批准，从零获得新成员关系，未解决的公共写确认也不能成为恢复关联依据。
- [ ] 退出者完成操作后离开房间界面并回到房间列表；移除者看到清晰的影响范围与二次确认，其他已打开设备通过 SSE 失效后立即移除该房间或该成员，页面不展示个人资源清理文案或入口。
- [ ] 自动化从运行中的同源应用经公开退出/移除命令、房间与成员查询、操作查询、SSE 和浏览器流程覆盖角色权限、版本冲突、多设备撤销、昵称复用及在途写晚到；测试通过公开 read model 证明数据不再可见并核对 adapter 调用，不直接改库或依赖私有表结构。
