# 24: 绑定并查看房主个人歌单

**What to build:** 在第一期已上线架构上，让房主把当前网易云账号已有的自建或收藏普通歌单绑定为可选个人来源，并在多个自建房间查看同一权威快照。

**Blocked by:** 09/读取并刷新权威公共歌单快照、23/执行第一期真实上线验收

**Status:** ready-for-agent

- [ ] 第二期升级后房间一级导航原子加入“我的歌单”，形成“公共歌单”“我的歌单”“房间成员”“房间设置”最终四入口；不保留第一期三入口兼容分支。
- [ ] 房主从当前核实网易云账号的完整实际清单选择目标，服务端确认目标由本人创建或已收藏，不能仅凭任意可读歌单 ID 绑定。
- [ ] 本人创建的普通歌单保存为可维护来源，已收藏他人普通歌单保存为只读来源；read model 和命令权限根据服务端能力计算。
- [ ] 绑定只建立 SongRoom 关联，不创建、复制、改名、排序或迁移云端歌曲；收藏来源不会被写入。
- [ ] 同一房主已有或收藏歌单可绑定到其多个自建房间，并引用同一真实账号加云端歌单 ID 的规范化快照；每个房间权限和绑定代次独立。
- [ ] 房主可在单个房间解除或更换绑定，不影响其他房间对同一目标的绑定，不删除自建歌单、不取消收藏也不删除作者歌单。
- [ ] “我的歌单”先展示最近快照并显式刷新，支持手动刷新、同步时间、读取失败保留旧快照和 10,000 首虚拟列表，不持续轮询。
- [ ] 未配置个人歌单时直接公共点歌继续可用，不将个人歌单展示为阻塞任务或自动创建云端资源。
- [ ] 其他成员只能从成员详情按第二期权限查看该歌单，不获得房主的维护或点歌来源资格；浏览器不能替换归属成员。
- [ ] 自动化覆盖自建、收藏、任意公开 ID 拒绝、跨房间共享快照、单房间解绑、收藏关系变化及第一期公共点歌回归。
