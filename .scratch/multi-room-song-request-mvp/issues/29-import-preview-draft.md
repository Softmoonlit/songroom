# 29: 预览文本导入并管理草稿

**What to build:** 让可维护个人歌单的归属成员粘贴文本、渐进搜索每行候选并在当前标签页调整预览，同时保证未提交草稿不持久化也不写网易云。

**Blocked by:** 10/搜索并直接公共点歌、24/绑定并查看房主个人歌单、25/创建并查看室友个人歌单

**Status:** ready-for-agent

- [ ] 导入只对自己的当前可维护个人歌单显示；收藏只读来源、他人个人歌单、未配置来源和公共歌单没有导入入口且服务端拒绝相关命令。
- [ ] 每个非空行去除首尾空白，支持两侧带空格的“歌名 - 歌手”及仅歌名，普通连字符不拆分；格式不完整时标记而不猜测。
- [ ] 输入最多 100 个非空行和总计 20,100 个 Unicode 码点，重复行计入行数；任一总量超限整轮拒绝且不启动上游搜索。
- [ ] 每行最多保留前 5 个单曲候选并默认第一条，同时明确提示默认项可能误选、提交前应核对；格式错误、未找到和搜索失败分别显示，不增加智能匹配、置信度、分页或加载更多。
- [ ] 导入创建短命内存 `searchId` 后立即返回，候选进度通过 SSE 失效后查询；整轮最多 100 行的搜索只占账号队列一个操作，不按行或上游请求占多项，并遵守房主真实账号的统一调度与容量。
- [ ] 修改输入、重搜或明确放弃会取消旧轮尚未发请求并丢弃晚到候选；搜索失败不自动重试。
- [ ] 用户可逐行改选候选、确认默认项或跳过；改选复用同一可访问弹窗，取消后保留原选择且不重新搜索，预览、改选、取消和跳过均不写个人或公共歌单。
- [ ] “我的歌单”的搜歌和导入入口不吸顶，导入输入页和结果页不吸顶；预览页只有已选数量与提交区吸顶，虚拟键盘和滚动时不遮挡当前行或候选弹窗。
- [ ] 输入、候选选择、二级页面和滚动位置只存在当前浏览器标签页的当前房间 React 内存，不进入 Query 缓存、URL、localStorage、sessionStorage 或数据库。
- [ ] 同房间切换四个一级入口保留草稿；刷新、关闭、明确放弃、返回房间列表、切换房间、退出账号或删除当前房间前提示，确认后丢弃；不同标签页草稿互相独立。
- [ ] Playwright 覆盖解析边界、100/101 行、码点上限、默认候选提示、五候选、改选取消不重搜、跳过、重搜晚到、房间切换提示、各页吸顶规则、虚拟键盘和窄屏预览布局。
