# 17: 删除房间及公共歌单

**What to build:** 让房主在看到最新影响范围并二次确认后永久删除房间，本地立即撤销全部访问并清除房间业务数据，同时仅为该房间由点歌台创建的专用公共歌单启动云端清理。

**Blocked by:** 07/安全创建公共歌单，13/识别失效公共歌单并重新创建，16/退出或移除房间成员

**Status:** ready-for-agent

- [ ] 只有房间房主可以查看和提交删房；室友、待审批者、非成员、其他房间房主及普通管理员不能删除，房主也不能以退出成员流程替代删房。
- [ ] 删除确认展示房间、当前成员与申请数量、公共歌单状态及可能产生的云端清理，并携带当前聚合版本；成员、邀请、申请、公共绑定或相关操作在确认后变化时拒绝旧确认并要求重新查看影响范围。
- [ ] 确认成功的本地事务立即永久删除房间、全部成员关系和昵称、邀请、待处理申请、公共绑定引用、公共快照引用、全部公共标签及成员可见操作数据，使所有设备马上失去访问；房间不提供恢复入口。
- [ ] 第一期删房只为该房间经点歌台专用创建且仍有具体云端 ID 的公共歌单建立最小清理任务；不查找、解除或删除个人歌单、个人绑定、个人快照、导入数据或室友专用资源，也不按名称推断删除资格。
- [ ] 本地删除不等待网易云授权或云端删除结果；它保留房主点歌台账号、用户级网易云绑定和其他房间，且不删除其他房间的公共歌单、快照、标签、成员或邀请。
- [ ] 删除事务停止所有尚未发出的房间操作；可能已发的歌曲写入和同步只可用于原目标最小确认，不能恢复房间、成员、绑定、标签或把结果写入其他房间及新目标。公共创建已取得具体 ID 时转为该目标清理，ID 仍未知时保留管理员核查证据，均不得恢复房间或再次创建。
- [ ] 有效授权下尚未发送的公共删除按账号调度执行一次，明确业务成功即可完成清理，不要求详情返回 404；授权不可用或删除结果未知时仍完成本地删房并保留待清理状态，由后续恢复票继续收敛。
- [ ] 删除并发、重复点击和多设备提交通过版本与幂等约束至多产生一次本地删除及一个目标清理责任；若公共歌单已被确认失效或没有公共绑定，不创建虚假删除任务。
- [ ] 房主确认后返回房间列表，并能看到与已删除房间分离的最小“公共歌单待清理”状态及下一步；其他设备经 SSE 失效后移除该房间，窄屏与宽屏均无残留可进入入口，清理中不把房间显示为可恢复。
- [ ] 自动化从运行中的同源应用经公开影响范围查询、删房命令、房间列表、清理状态、SSE 和浏览器页面覆盖角色拒绝、确认版本冲突、无公共歌单、正常删除、无授权、公共创建已获 ID 或 ID 未知时删房以及其他在途结果晚到；脚本化 adapter 证明只触及具体公共专用目标，测试不得直接写数据库或调用私有清理步骤。
