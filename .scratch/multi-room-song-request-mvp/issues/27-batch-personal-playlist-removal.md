# 27: 批量删除和清空个人歌单

**What to build:** 让可维护个人歌单的归属成员在明确二次确认后批量删除所选歌曲，或清空执行开始时实际看到的歌曲集合，同时保留逐项真实结果。

**Blocked by:** 26/单首维护可写个人歌单

**Status:** ready-for-agent

- [ ] 只有当前归属成员且来源仍可写时显示批量选择、批量删除和清空动作；收藏来源和他人个人歌单没有这些入口且命令端拒绝。
- [ ] 批量删除确认展示所选数量和影响，携带当前绑定与快照聚合版本；确认前状态变化会拒绝旧确认并要求重新查看。
- [ ] 清空在执行开始时先完整读取目标并固定本次所见歌曲 ID 集合，确认明确说明只处理该集合，不循环追删官方客户端后来新增的歌曲。
- [ ] 删除按歌曲 ID 去重并逐首执行，每首写后完整读回；已不存在项按当前事实处理，不因单项明确失败回滚已成功项。
- [ ] 长批量任务每次上游请求后公平让出账号执行权，但同目标冲突操作不得插入该操作受保护的阶段。
- [ ] 任一项结果未知时暂停同目标后续冲突写并进入只读确认，不自动重发该项；已确认成功项保持成功且不回滚。
- [ ] 最终结果逐项区分已删除、原本不存在、明确失败和待确认；清空后若外部新增或失败项仍在，不得显示为空歌单。
- [ ] 取消或关闭页面不取消已提交操作；当前操作和逐项结果可跨页面查询，终结并看完后按规格清理明细。
- [ ] 绑定、成员、授权或可写能力在执行中撤销时停止尚未发步骤，晚到结果不能恢复旧绑定或继续删除新代次目标。
- [ ] 受控 adapter 测试覆盖版本冲突、官方客户端并发新增/删除、部分失败、未知暂停、公平让出、重启恢复和最终真实快照。
