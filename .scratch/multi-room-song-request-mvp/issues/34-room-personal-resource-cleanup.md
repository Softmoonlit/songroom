# 34: 扩展删房清理个人资源

**What to build:** 在第二期删房时，除第一期公共资源清理外，删除该房间所有室友专用个人歌单，并只解除房主已有或收藏个人歌单的本地绑定。

**Blocked by:** 24/绑定并查看房主个人歌单、32/破坏性更换网易云账号、33/扩展成员退出清理个人资源

**Status:** ready-for-agent

- [ ] 第一阶段删房的房主权限、影响范围、版本确认、本地立即硬删除、公共歌单清理和不可恢复行为保持不变。
- [ ] 影响确认列出公共歌单、所有室友专用个人歌单、房主已有或收藏绑定的不同处置，以及当前标签页存在时未提交导入草稿将丢失的影响，不能用一个模糊数量掩盖删除与解绑差异。
- [ ] 本地事务为每个仍有具体 ID 和专用创建证据的室友个人歌单创建最小删除任务，并立即删除房间、成员、绑定、快照引用、标签、申请和已提交业务结果。
- [ ] 房主已有自建或收藏个人歌单只解除当前房间绑定，不删除云端歌单、不取消收藏、不回滚歌曲，其他房间对同一规范化目标的绑定继续有效。
- [ ] 所有专用删除始终使用创建这些资源的原真实网易云账号和具体 ID，账号已更换时不得用新绑定处理旧目标。
- [ ] 每个云端删除任务独立收敛；一个目标失败或等待授权不恢复房间，也不阻止其他任务完成。
- [ ] 创建已获 ID 但尚未关联、目标已确认删除和创建 ID 未知等状态分别转换为必要清理或管理员核查，不按名称补找。
- [ ] 晚到个人维护、导入、来源点歌、快照和创建结果只能用于原目标必要确认，不能恢复已删除房间或影响共用目标。
- [ ] 页面二次确认与完成反馈清楚区分本地房间已删除和云端清理仍在进行；发起删房的当前标签页确认后丢弃该房间内存草稿，普通用户没有任意重试删除能力。
- [ ] 崩溃与集成测试覆盖多个室友目标、房主共享自建/收藏目标、账号换代、部分清理未知、晚到创建和其他房间不受影响。
