# 04: 创建、列出并进入房间

**What to build:** 让已绑定网易云的用户创建多个房间，在主页只看到自己创建或已加入的房间，并进入适合宽屏和手机使用的第一期房间工作区。

**Blocked by:** 03/安全扫码绑定网易云账号

**Status:** ready-for-agent

- [ ] 建房要求当前有效网易云授权，并让用户确认当前核实后的网易云身份；浏览器不能借此提交任意真实账号 ID。
- [ ] 用户填写房间名称和自己的房间昵称后创建房间，成为不可转让且不能主动退出的房主；建房只建立房间、房主成员和邀请，不创建云端歌单。
- [ ] 房间名称可以重复；成员昵称按去除首尾空白并 NFC 规范化后的大小写敏感文本在当前房间唯一。
- [ ] 主页只列出当前账号创建或仍是成员的房间，并显示足够的房间名、角色和进入动作；不提供全站目录、搜索或按名称加入。
- [ ] 一个账号最多自建 3 个房间、当前归属 10 个房间，全站最多 20 个房间；并发越界只有合法数量成功，已有数据不被删除或挤占。
- [ ] 进入房间默认显示“公共歌单”，第一期只渲染“公共歌单”“房间成员”“房间设置”三个一级入口，不显示空置、禁用或预告性质的“我的歌单”。
- [ ] 宽屏使用稳定侧栏，窄屏使用固定底部三栏；页面显示房间名称和当前角色，支持返回房间列表，320px 起无横向溢出或文字重叠，搜索或表单输入唤起虚拟键盘时底栏暂时隐藏且内容不被遮挡。
- [ ] 每个一级入口独立保留二级页面与滚动位置，重按当前入口回顶；离开或切换房间后清除原房间导航状态。
- [ ] 页面、查询和命令始终从当前会话及服务端成员关系推导房间可见性，伪造房间 ID、角色或房主账号均不能越权。
- [ ] 完整应用和 Playwright 测试覆盖未授权建房、并发容量、重复名称、昵称冲突、房间列表隔离、三入口导航及 320px、900px、1440px 布局；房间改名与成员身份管理由后续 ticket 承接。
