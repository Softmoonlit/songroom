# 26：单首维护本人专用个人歌单

**What to build:** 房主与室友按相同规则维护自己在本房间的专用个人歌单。搜索及逐首添加沿用搜索页工单 02 的已交付能力，本票补齐单首删除、云端确认和操作恢复，不扩展为批量维护。

**Blocked by:** 11/恢复未知歌曲写入而不重发、[统一成员专用个人歌单](../../song-search-page/issues/01-unify-dedicated-personal-playlists.md)、[解耦全网搜索并实现个人逐首添加](../../song-search-page/issues/02-search-and-personal-song-addition.md)（均已具备）

**Status:** resolved

## 当前规则与范围

- 以[搜索及个人点歌规格](../../song-search-page/spec.md)、[体验修订规格](../../room-experience-refinement/spec.md)及 [ADR-0002](../../../docs/adr/0002-dedicated-personal-playlists-and-song-request-flow.md) 为准。废弃原票的房主已有/收藏来源、只读收藏和跨房间个人共用条款，不新增兼容路径。
- 搜索只向本人的专用个人歌单添加，公共逐首点歌仍须从本人个人来源发起；删除个人歌曲不删除公共歌曲或公共点歌人标签。
- 单删直接提交；批量删除和清空的二次确认属于 27。未配置公共歌单不妨碍个人维护。
- 明确换号终止原账号全部业务和恢复任务，见 [ADR-0003](../../../docs/adr/0003-account-switch-ends-old-account-recovery.md)；本票验证既有授权及绑定代次隔离，不新增工单 32 的换号命令。

## 验收清单

- [x] 只有当前归属成员可以维护本人专用个人歌单；房主与室友相同，他人查看仅有只读歌曲，浏览器不能指定他人目标或账号。
- [x] 已有搜索和添加保持短命搜索、明确提交才写入、按歌曲 ID 去重、同名不同 ID 可共存和完整云端读回语义。
- [x] 单删受理及执行重新核验成员、归属、房主授权、绑定代次、云端账号及可写目标；未配置公共歌单仍能删除。
- [x] 本地快照不能单独证明歌曲已删除；执行前完整读云端，确认已不存在时跳过删除写入，其余情况逐次最多发送一个单首删除请求，再完整读回云端实际集合和顺序。
- [x] 操作意图和发送边界持久化；同键同内容返回原状态、不同内容拒绝，发送中断或读回失败/矛盾进入待确认，只查询确认、不自动重发或回滚。
- [x] 每成员同房间一个未完成写操作；个人增删与以该歌单为来源的公共点歌协调冲突；统一账号调度的串行、启动间隔、全站并行和公平让出不被绕过。
- [x] 恢复与补查沿用既有原账号重授权、约 5 秒/30 秒/2 分钟有界补查、手动同步确认和管理员普通未知操作终结；终态按既有 24 小时规则清理最小结果与防重记录。
- [x] 成员撤权、删房和绑定/授权代次变化阻止未发步骤，晚到结果不能恢复旧成员数据、旧快照或绑定；服务重启不重发可能已发送的删除。
- [x] 页面区分排队、处理中、待确认、等待授权、明确失败和成功；未知时保留歌曲并禁止重复操作，刷新或重新进入可查询服务端当前操作，只有云端确认成功才移除歌曲。
- [x] 自动化覆盖房主/室友、单删、已不存在、去重、越权、同目标及来源冲突、读回未知、重启和撤权竞态；320/390/1440px 按钮可达、无横向溢出，并完成类型检查、完整测试和双轴审查。
