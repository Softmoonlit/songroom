# 26: 单首维护可写个人歌单

**What to build:** 让个人歌单归属成员在可维护来源中搜索添加或单首删除歌曲，并通过写后读回看到网易云实际集合和顺序。

**Blocked by:** 11/恢复未知歌曲写入而不重发、24/绑定并查看房主个人歌单、25/创建并查看室友个人歌单

**Status:** ready-for-agent

- [ ] 只有当前绑定的归属成员可维护个人歌单；房主本人自建来源和室友专用来源可写，收藏来源及他人个人歌单不显示也不接受维护命令。
- [ ] 搜索使用短命内存状态并遵守统一账号调度，查看候选和取消不写云端；明确添加后才建立持久操作。
- [ ] 添加受理时重新核验成员、归属、房主授权、绑定代次、目标可写性、冲突和成员单未完成操作限制。
- [ ] 目标已有歌曲时按歌曲 ID 跳过写入且不移动顺序；同名不同 ID 可共存，不按名称、歌手或专辑合并。
- [ ] 新增和单首删除均逐次最多发送一个对应上游写请求，并在每次写后完整读回，以真实集合和顺序更新共享快照。
- [ ] 写响应成功但读回失败或矛盾时进入待确认并阻塞同目标冲突写，不能假报成功、自动重发或回滚其他已确认结果。
- [ ] 房主在一个房间维护跨房间共享的自建歌单时，所有有效绑定看到同一新快照，但各房间权限保持独立。
- [ ] 界面显示排队、处理中、待确认、明确失败和成功，不提供排序、改云端名称或编辑他人个人歌单能力。
- [ ] 绑定撤销、收藏能力变化、成员撤权、账号换代或目标删除会停止尚未发步骤，晚到结果只用于原目标收敛。
- [ ] 自动化覆盖添加、已有 ID、同名不同 ID、单删、收藏只读、他人越权、共享快照、读回未知和撤权竞态。
