### 2. 真实网易云扫码、建房与点歌链路实测及线上修复

- **扫码建房流程实测**：
  - 用户成功扫码授权网易云账号（账号 ID `17982997635`，昵称 `kilongme`）；
  - 成功创建房间并在网易云上新建公共歌单 `songroom-test-公共`（歌单 ID `18466614671`）。
- **点歌写后读回 PARSE_ERROR 异常定位与修复**：
  - **现象**：点歌《猪猪侠》（歌曲 ID `34324641`）后，网易云客户端已添加入单，但点歌台提示“创建结果待确认，网易云返回的结果无法识别”，公共歌单未展示。
  - **根因**：网易云单曲/动画原声《猪猪侠》的专辑信息为空（`al.name: ""`），而系统在读回快照时校验 `!song.album || song.album.length === 0`，将合法空专辑名曲目误判为数据畸形（`PARSE_ERROR`），导致写后读回校验失败而进入 `awaitingConfirmation`。
  - **修复措施**：
    1. 修改 `public-playlists.ts`，将校验放宽至 `typeof song.album !== "string"`（合法允许空专辑名）；
    2. 修改 `worker.cts` 中的 `song` 解析提取，确保 `album: (value.al ?? value.album)?.name ?? ""` 安全容错；
    3. 优化 `PublicPlaylistPane.tsx` 的前端曲目元信息展示，空专辑时不显示多余分隔符；
    4. 补齐空专辑名曲目快照同步的单元测试并通过。
  - **恢复结果**：
    代码部署后触发公共歌单快照同步，歌单成功读回包含《猪猪侠》（歌手：陈洁丽，专辑：空），操作状态从 `awaitingConfirmation` 自动证实收敛为 `succeeded`，点歌人标签 `clb` 正确写入并持久化，公共歌单曲目正常展示。
